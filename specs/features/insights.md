# 洞察 + 感情トラッキング 仕様書

## 基本情報
- 担当Agent: Agent D (Engagement)
- 関連画面: app/(tabs)/history.tsx（気分トラッキングセクション）
- 依存する機能: 認証、日記（感情データ）
- 依存される機能: なし

## 目的
毎日の気分を記録し、直近7日間の推移を可視化する。Proユーザーには詳細分析を提供する。
データの蓄積を「可視化」することで価値を実感させ、解約防止と継続的な利用習慣の形成につなげる。

## ユーザーストーリー
- [ ] ユーザーとして、今日の気分を絵文字で記録したい。なぜなら日々の感情を簡単にトラッキングしたいから。
- [ ] ユーザーとして、直近7日間の気分の推移を確認したい。なぜなら自分の感情パターンを把握したいから。
- [ ] Proユーザーとして、詳細な感情分析レポートを見たい。なぜならデータに基づいた自己理解を深めたいから。
- [ ] Freeユーザーとして、詳細分析の価値を理解してProにアップグレードしたい。なぜなら感情トラッキングをより活用したいから。

## 受け入れ条件（Acceptance Criteria）

### AC-1: 今日の気分を記録できる
- Given: 認証済みユーザーが洞察タブを開いている
- When: 6種類の気分絵文字（とても良い/良い/普通/悲しい/イライラ/疲れた）から1つを選択する
- Then: 選択した気分が `mood_records` テーブルに当日日付で保存され、選択済みの絵文字がハイライトされる

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 当日すでに気分を記録済み | 既存の記録が選択状態で表示される（上書き可能） |
| 日付が変わった直後（0:00） | 新しい日付として未記録状態で表示される |
| ネットワーク切断中に記録 | エラーメッセージ表示、選択状態は元に戻る |
| タイムゾーンが異なるユーザー | ユーザーのタイムゾーン（profiles.timezone）基準で日付判定 |

#### テスト観点
- [ ] 正常系: 6種類の気分がそれぞれ記録できる
- [ ] 正常系: 記録後にUIが即座に更新される
- [ ] 異常系: ネットワークエラー時に選択が元に戻る
- [ ] 境界値: 日付変更境界（23:59 → 0:00）での動作

### AC-2: 気分を変更（上書き）できる
- Given: 当日すでに気分を記録済みのユーザーが洞察タブを開いている
- When: 別の気分絵文字を選択する
- Then: `mood_records` テーブルの当日レコードが upsert で上書きされ、新しい気分がハイライトされる

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 同じ気分を再度タップ | 何も変更されない（不要なAPIコールを防止） |
| 変更中にネットワークエラー | エラーメッセージ表示、前の気分が選択状態に戻る |
| 短時間で連続変更 | デバウンス処理で最後の選択のみ保存 |

#### テスト観点
- [ ] 正常系: 気分の上書きが正常に動作する
- [ ] 正常系: 上書き後に履歴表示も更新される
- [ ] 異常系: 同じ気分の再選択で不要なAPIコールが発生しない
- [ ] 性能: 連続変更がデバウンスされる

### AC-3: 直近7日間の気分履歴が表示される
- Given: ユーザーが過去数日間の気分を記録している
- When: 洞察タブを開く
- Then: 直近7日間の気分がドットチャートまたは絵文字一覧で時系列表示される。未記録の日はグレーアウト表示

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 7日間すべて未記録 | 全日がグレーアウト表示、「気分を記録してみよう」メッセージ |
| 一部の日が未記録 | 記録済みの日のみ気分表示、未記録日はグレーアウト |
| 7日間すべて記録済み | 全日の気分が表示される |
| アプリ初回利用日から7日未満 | 利用開始日以降の日数分のみ表示 |

#### テスト観点
- [ ] 正常系: 7日間の気分が正しく時系列表示される
- [ ] 正常系: 未記録日がグレーアウト表示される
- [ ] 境界値: 全日未記録時の空状態表示
- [ ] 境界値: 全日記録済み時の完全表示
- [ ] 境界値: 利用開始から7日未満の場合の表示

### AC-4: Freeユーザーにはアップグレード誘導が表示される
- Given: Freeプランのユーザーがアプリにログインしている
- When: 洞察タブをタップする
- Then: 基本的な気分記録UIは利用可能で、詳細分析エリアには「インサイトはProの機能です」メッセージと「Proにアップグレード」ボタンが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| トライアル期間中のユーザー | Pro同様に詳細分析を利用可能 |
| サブスクリプション期限切れ | Freeユーザーと同じアップグレード誘導を表示 |
| グレースピリオド中 | Pro同様に詳細分析を利用可能 |
| 「Proにアップグレード」タップ | ペイウォール画面 (paywall)/index.tsx に遷移 |

#### テスト観点
- [ ] 正常系: Freeユーザーに詳細分析のアップグレード誘導が表示される
- [ ] 正常系: Freeユーザーでも基本的な気分記録は利用可能
- [ ] 正常系: アップグレードボタンタップでペイウォールに遷移
- [ ] 正常系: トライアルユーザーは詳細分析を利用可能
- [ ] 正常系: グレースピリオド中のユーザーは詳細分析を利用可能
- [ ] 異常系: 期限切れユーザーにアップグレード誘導が表示される

### AC-5: データの更新がリアルタイムに反映される
- Given: ユーザーが洞察タブを表示している
- When: 気分を記録または変更する
- Then: 7日間の気分履歴チャートが即座に更新され、最新の状態が反映される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 日記タブで気分を選択して戻った場合 | 日記の気分データが洞察タブの履歴にも反映される |
| 別デバイスで気分を記録した場合 | プルダウンリフレッシュまたはタブ切替時にデータ同期 |
| キャッシュと最新データの不整合 | Supabaseからの最新データが優先される |

#### テスト観点
- [ ] 正常系: 気分記録後に履歴チャートが即座に更新される
- [ ] 正常系: タブ切替時にデータが同期される
- [ ] 正常系: プルダウンリフレッシュでデータが更新される
- [ ] 異常系: キャッシュと最新データの不整合が正しく解消される

## 画面仕様

### 洞察タブ（insights.tsx）
- 入力項目: 気分絵文字選択（6種類）
- 表示項目: 今日の気分セクション、直近7日間の気分履歴チャート、Proユーザー向け詳細分析エリア（将来実装予定プレースホルダー）
- アクション: 気分絵文字タップで記録、プルダウンリフレッシュ、アップグレードボタン（Freeユーザー）
- 状態遷移: ローディング → 表示（記録済み/未記録） / エラー表示

### 気分絵文字の定義
| 値 | 表示 | 意味 |
|----|------|------|
| great | 絵文字 | とても良い |
| good | 絵文字 | 良い |
| neutral | 絵文字 | 普通 |
| sad | 絵文字 | 悲しい |
| angry | 絵文字 | イライラ |
| tired | 絵文字 | 疲れた |

## エッジケース・エラーケース
| ケース | 期待される動作 |
|--------|--------------|
| Supabase接続エラー | インラインエラー表示、既存キャッシュデータで表示 |
| データ読み込み中 | スケルトンローディング表示 |
| 気分データが全くない新規ユーザー | 気分記録の誘導メッセージを表示 |
| 日記機能との気分データ競合 | mood_records テーブルの upsert で最新データが優先 |

## データ仕様
- 使用するテーブル: `mood_records`
- 必要なAPI: Supabase クエリ（mood_records の CRUD）
- 連携: 日記機能（journal_entries）の気分データと mood_records を同期
- キャッシュ: Zustand persist、5分間TTL

- [ ] 異常系テスト: 日記機能との気分データ同期
