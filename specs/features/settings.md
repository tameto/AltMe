# 設定 + OpenClawインスタンス管理 仕様書

## 基本情報
- 機能名: 設定 + OpenClawインスタンス管理
- 関連画面: app/(tabs)/settings.tsx, app/subscription-manage.tsx
- 依存する機能: 認証、課金、OpenClawプロビジョニング
- 依存される機能: なし

## 目的
ユーザーがプロフィール、サブスクリプション、OpenClawインスタンスの状態を管理する。
アプリ全体の設定とProユーザー向けのインフラ管理機能を統合的に提供する。

## ユーザーストーリー
- [ ] ユーザーとして、プロフィール（表示名）を変更したい。なぜなら適切な名前で表示されたいから。
- [ ] ユーザーとして、AIツインの名前を変更したい。なぜならもっと良い名前を思いついたから。
- [ ] Proユーザーとして、サブスクリプションの状態を確認したい。なぜなら契約内容を把握したいから。
- [ ] Proユーザーとして、OpenClawインスタンスの状態を確認したい。なぜならAIツインが正常に動作しているか知りたいから。
- [ ] ユーザーとして、安全にログアウトしたい。なぜなら端末を他人に貸す場合があるから。
- [ ] ユーザーとして、性格診断をやり直したい。なぜなら自分の性格をより正確に反映させたいから。
- [ ] ユーザーとして、自分のMBTIタイプを入力したい。なぜならMBTIに基づいてAIツインをより自分に近づけたいから。
- [ ] ユーザーとして、プッシュ通知のカテゴリごとにON/OFFを切り替えたい。なぜなら必要な通知だけ受け取りたいから。
- [ ] ユーザーとして、日記リマインダーの時刻を変更したい。なぜなら自分の生活リズムに合わせたいから。

## 設定項目
- プロフィール編集（表示名変更）
- AIツイン設定
  - ツイン名変更
  - MBTI入力（16タイプから選択、任意）
  - AIアイコン変更（5パターンから再選択）
  - 口調パターン変更（5種類から再選択、SOUL.md再生成トリガー）
- 性格診断やり直し
- サブスクリプション管理（Pro表示、解約リンク）
- OpenClawインスタンス状態表示（Proのみ）
  - status: provisioning / running / stopped / error
  - 再起動ボタン（error時）
  - IPアドレス表示（デバッグ用）
  - 注: Twin Infoタブにもステータス表示されるが、再起動等の操作は設定画面に配置
- 通知設定（チャット通知、日記リマインダー、コミュニティ通知、マーケティング通知のON/OFF）
- アカウント削除
- ログアウト
- ヘルプ/FAQ、利用規約、プライバシーポリシーリンク
- アプリバージョン表示

## 受け入れ条件（Acceptance Criteria）

### AC-1: プロフィール（表示名）を編集できる
- Given: 認証済みのユーザーが設定画面を表示している
- When: 「プロフィール編集」セクションの表示名フィールドをタップし、新しい名前を入力して「保存」をタップする
- Then:
  - `profiles`テーブルの`display_name`が更新される
  - 成功トーストメッセージが表示される（「プロフィールを更新しました」）
  - 画面上の表示名が即時反映される
  - Zustandの状態が更新される
- エッジケース:
  - 空文字で保存しようとした場合、バリデーションエラー（「名前を入力してください」）
  - 50文字を超える場合、入力が制限される
  - ネットワークエラー時、「保存に失敗しました。再試行してください」表示
  - 同じ名前で保存しようとした場合、APIコールは行わない（変更検知）
  - 絵文字・日本語・英数字は全て許可する

### AC-2: AIツインの設定を変更できる（名前・アイコン・口調）
- Given: 認証済みのユーザーが設定画面を表示している
- When: 「AIツイン設定」セクションの各フィールドを編集して「保存」をタップする
- Then:
  - `profiles`テーブルの`twin_name`, `avatar_icon`, `speech_tone` が更新される
  - OpenClawインスタンスが稼働中の場合、SOUL.mdが再生成される（Edge Function `update-soul-md` 呼出、アイコン・口調を含む）
  - 成功トーストメッセージが表示される（「設定を更新しました」）
  - チャット画面のヘッダー名も即時反映される
- サブAC:
  - **AC-2.1**: ツイン名変更
    - 空文字で保存しようとした場合、バリデーションエラー（「ツイン名を入力してください」）
    - 20文字を超える場合、入力が制限される
    - OpenClawインスタンスが停止中の場合、DBのみ更新（次回起動時にSOUL.md反映）
  - **AC-2.4**: MBTI入力
    - 16タイプから選択（INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP, ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP）
    - 任意入力（NULL許容）。設定済みMBTIのクリアも可能
    - `profiles.mbti_type` TEXT NULL に保存
    - Pro時: SOUL.mdの `personality_traits` セクションにMBTI特性を追加（例: INTJ → 「論理的思考を好み、戦略的に物事を考える。独立心が強く、効率を重視する」）
    - Edge Function `update-soul-md` 呼出
    - インスタンス停止中はDBのみ更新
    - ツイン情報画面にMBTIタイプが表示される
  - **AC-2.2**: AIアイコン変更
    - 5パターン（geometric/cosmic/organic/tech/zen）から再選択可能
    - 選択するとプレビューが更新される
    - SOUL.md再生成トリガー
  - **AC-2.3**: 口調パターン変更
    - 5種類（polite/friendly/intellectual/mentor/tsundere）から再選択可能
    - 会話サンプルカード表示
    - SOUL.md再生成トリガー（必須）
- エッジケース:
  - SOUL.md更新がエラーの場合、DB更新は成功として扱い、SOUL.md更新はバックグラウンドリトライ
  - アイコン・口調変更時に「SOUL.mdを再生成中...」の進行状況表示

### AC-3: Proユーザーがサブスクリプション状態を確認できる
- Given: Pro課金済みのユーザーが設定画面を表示している
- When: 「サブスクリプション」セクションが表示される
- Then:
  - 現在のプラン名が表示される（「Proプラン」）
  - 課金タイプが表示される（「月額」または「年額」）
  - 次回更新日（または有効期限）が表示される
  - 「サブスクリプション管理」リンクが表示される
  - リンクタップでapp/subscription-manage.tsxまたはOS標準のサブスクリプション管理画面に遷移する
- エッジケース:
  - 無料ユーザーの場合、「Freeプラン」と表示され、「Proにアップグレード」ボタンを表示
  - トライアル中の場合、「無料トライアル中（残りX日）」を表示
  - 解約済みだが有効期限内の場合、「解約済み（YYYY/MM/DDまで有効）」を表示
  - RevenueCat APIエラー時、「状態を取得できませんでした」表示（キャッシュがあればキャッシュ表示）

### AC-4: ProユーザーがOpenClawインスタンスの状態を確認できる
- Given: Pro課金済みのユーザーが設定画面を表示している
- When: 「AIツインインスタンス」セクションが表示される
- Then:
  - 現在のステータスがバッジで表示される:
    - `provisioning`: 黄色バッジ「セットアップ中...」+ スピナー
    - `running`: 緑色バッジ「稼働中」
    - `stopped`: グレーバッジ「停止中」
    - `error`: 赤色バッジ「エラー」
  - ステータスはポーリング（30秒間隔）またはリアルタイムサブスクリプションで更新
  - IPアドレスが表示される（デバッグモード時のみ、または長押しで表示）
- エッジケース:
  - 無料ユーザーにはこのセクションが表示されない
  - インスタンスが未作成の場合、「インスタンス未作成」と表示
  - ステータス取得エラー時、最後の既知ステータスをキャッシュ表示 + 「更新に失敗しました」注記

### AC-5: OpenClawインスタンスがerror時に再試行できる
- Given: OpenClawインスタンスのステータスが`error`である
- When: 「再起動」ボタンをタップする
- Then:
  - 確認ダイアログが表示される（「インスタンスを再起動しますか？」）
  - 「再起動」をタップすると、Edge Function `restart-openclaw` が呼び出される
  - ステータスが`provisioning`に変わり、スピナーが表示される
  - 再起動が完了するとステータスが`running`に更新される
  - 成功トーストメッセージが表示される（「インスタンスを再起動しました」）
- エッジケース:
  - 再起動中に再度「再起動」をタップした場合、ボタンが非活性（二重実行防止）
  - 再起動がタイムアウト（120秒以上）した場合、「再起動に失敗しました。サポートに連絡してください」表示
  - 再起動中にアプリを閉じた場合、次回起動時にステータスをチェック
  - Edge Functionエラー時、「再起動に失敗しました。しばらく後に再試行してください」表示
  - 短時間（5分以内）に3回以上再起動を試行した場合、クールダウン表示（「しばらくお待ちください」）

### AC-6: ログアウトするとOpenClawとの接続が切断される
- Given: 認証済みのユーザーが設定画面を表示している
- When: 「ログアウト」をタップし、確認ダイアログで「ログアウト」を選択する
- Then:
  - OpenClawとのWebSocket接続が切断される
  - Supabaseセッションが無効化される
  - SecureStoreからトークンが削除される
  - Zustandの全状態がリセットされる
  - ローカルキャッシュ（チャット履歴等）がクリアされる
  - ログイン画面にリダイレクトされる
- エッジケース:
  - ログアウト中にネットワークエラーが発生した場合でも、ローカルのセッション・キャッシュは必ず削除される
  - 確認ダイアログでキャンセルした場合、何も起こらない
  - OpenClaw接続がすでに切断されている場合、エラーにならない（切断済みとして処理）
  - ログアウト処理中はローディングインジケーターを表示し、他の操作を無効化する

### AC-7: ユーザーがアカウントを削除できる
- Given: 認証済みのユーザーが設定画面を表示している
- When: 「アカウント削除」をタップする
- Then:
  - 確認ダイアログが表示される（「アカウントを削除すると、すべてのデータが完全に削除されます。この操作は取り消せません。」）
  - 確認テキスト入力を求める（「削除」と入力）
  - 「削除を確定」をタップすると:
    - OpenClawインスタンスが存在する場合、destroy-openclawが呼び出される
    - RevenueCatのサブスクリプションがキャンセルされる
    - Supabase上の全ユーザーデータがCASCADE削除される
    - Supabase Authからユーザーが削除される
    - アプリがログイン画面にリダイレクトされる
- エッジケース:
  - 削除処理中にネットワークエラーが発生した場合、リトライまたはサポート連絡を案内
  - OpenClawインスタンスの削除が失敗した場合でも、ユーザーアカウントの削除は続行
  - トライアル中のユーザーの場合、RevenueCatでキャンセルも実行
  - Apple審査基準: 削除ボタンは設定画面内で容易に見つかる位置に配置
- テスト観点:
  - 正常系: アカウント削除後に全データが削除されていること
  - 正常系: ログイン画面にリダイレクトされること
  - 異常系: ネットワークエラー時の適切なハンドリング
  - セキュリティ: 他ユーザーのアカウントを削除できないこと

### AC-8: プッシュ通知が正しく配信される
- Given: 認証済みのユーザーがアプリをインストールしている
- When: アプリ起動時に通知権限をリクエストし許可される
- Then:
  - Expo Push Token が取得され `push_tokens` テーブルに upsert される
  - 通知トリガーに応じてプッシュ通知が配信される:
    - AIチャット: ツインからの返信時（アプリがバックグラウンドの場合のみ）
    - 日記リマインダー: 設定時刻（デフォルト21:00）
    - コミュニティ: 自分のエージェントが発言した時
    - マーケティング: 管理側から送信
  - Edge Function `send-push-notification` が Expo Push API を呼び出して通知配信
- エッジケース:
  - 通知権限が拒否された場合、通知設定画面に「OS設定で通知を許可してください」と表示
  - トークンが無効化された場合（アプリ再インストール等）、次回起動時に更新
  - 複数デバイスにログインしている場合、全デバイスに通知配信

### AC-9: 通知カテゴリごとにON/OFFを設定できる
- Given: 認証済みのユーザーが設定画面の通知設定セクションを表示している
- When: 各通知カテゴリのトグルを切り替える
- Then:
  - `notification_settings` テーブルの対応カラムが更新される
  - OFFにしたカテゴリの通知は配信されなくなる
  - 通知カテゴリとデフォルト値:
    - チャット通知: デフォルトON (`chat_enabled`)
    - 日記リマインダー: デフォルトON (`journal_reminder_enabled`)、時刻設定可能 (`journal_reminder_time` デフォルト '21:00')
    - コミュニティ通知: デフォルトON (`community_enabled`)
    - マーケティング通知: デフォルトOFF (`marketing_enabled`)
- エッジケース:
  - デバイスのシステム通知設定がOFFの場合、アプリ内で「OS設定で通知を許可してください」と表示
  - 日記リマインダー時刻変更後、次回から新しい時刻で通知
  - `notification_settings` レコードが存在しない場合、デフォルト値で自動作成

## 画面仕様

### 設定画面 (app/(tabs)/settings.tsx)
- 入力項目:
  - 表示名テキストフィールド
  - AIツイン名テキストフィールド
  - MBTI選択（16タイプ ドロップダウン/4x4グリッド）
  - 通知設定（チャット通知/日記リマインダー/コミュニティ通知/マーケティング通知 各ON/OFFトグル）
  - 日記リマインダー時刻ピッカー
- 表示項目:
  - ユーザーアバター（プロバイダから取得）
  - 表示名
  - AIツイン名
  - MBTIタイプ（設定済みの場合）
  - サブスクリプション情報セクション
  - OpenClawインスタンス情報セクション（Proのみ）
  - 性格診断やり直しリンク
  - 通知設定セクション（4カテゴリ + 日記リマインダー時刻）
  - アカウント削除ボタン
  - ログアウトボタン
  - ヘルプ/FAQリンク
  - 利用規約リンク
  - プライバシーポリシーリンク
  - アプリバージョン
- アクション:
  - 表示名編集 → 保存 → profiles更新
  - ツイン名編集 → 保存 → profiles更新 + SOUL.md更新
  - MBTI選択 → 保存 → profiles.mbti_type更新 + SOUL.md更新（Pro）
  - 性格診断やり直し → オンボーディング（personality-quiz）へ遷移
  - サブスクリプション管理 → 管理画面遷移
  - インスタンス再起動 → Edge Function呼出
  - 通知カテゴリ ON/OFF → notification_settings テーブル更新
  - 日記リマインダー時刻変更 → notification_settings.journal_reminder_time 更新
  - アカウント削除 → 確認ダイアログ → テキスト入力確認 → 全データ削除
  - ログアウト → 確認ダイアログ → セッション破棄
  - ヘルプ/FAQ → WebView or 外部ブラウザ
  - 利用規約/プライバシーポリシー → WebView or 外部ブラウザ
- 状態遷移:
  - 表示モード → 編集モード（フィールドタップ時）→ 保存中 → 表示モード
  - ログアウト確認 → ログアウト処理中 → ログイン画面

### サブスクリプション管理画面 (app/subscription-manage.tsx)
- 入力項目: なし
- 表示項目:
  - 現在のプラン詳細
  - 課金履歴
  - プラン変更オプション（月額 ↔ 年額）
  - 解約リンク
- アクション:
  - プラン変更 → RevenueCat API
  - 解約 → OS標準のサブスクリプション管理画面を開く
- 状態遷移: なし（情報表示画面）

## エッジケース・エラーケース
| ケース | 期待される動作 |
|--------|--------------|
| ネットワーク未接続時にプロフィール保存 | 「ネットワークに接続してください」エラー表示 |
| OpenClawインスタンスの状態取得タイムアウト | キャッシュ表示 + 「最終更新: X分前」注記 |
| RevenueCat APIエラー | キャッシュまたは「取得できませんでした」表示 |
| 性格診断やり直し中にアプリ終了 | 次回起動時は通常のメインタブへ（やり直しは最初から） |
| 課金解約後にOpenClawインスタンスが停止 | ステータスが`stopped`に変更、インスタンス情報は表示するが操作不可 |
| 表示名にHTML/スクリプトタグ | サニタイズして保存 |
| 同時に複数フィールドを編集中にアプリ終了 | 未保存の変更は破棄される（確認なし、MVPのため） |

## データ仕様
- 使用するテーブル/コレクション:
  - `profiles`（`display_name`, `twin_name`, `mbti_type`の読み書き）
  - `openclaw_instances`（インスタンスステータスの読み取り）
  - `personality_results`（性格診断やり直し時の新規INSERT）
  - `notification_settings`（通知カテゴリごとのON/OFF設定）
  - `push_tokens`（Expo Push Token の登録・更新）
- 必要なAPI:
  - Supabase DB: `profiles` テーブル SELECT/UPDATE
  - Supabase DB: `openclaw_instances` テーブル SELECT
  - Supabase Edge Function: `update-soul-md`（ツイン名・MBTI変更時）
  - Supabase Edge Function: `send-push-notification`（プッシュ通知送信）
  - Supabase Edge Function: `restart-openclaw`（インスタンス再起動）
  - RevenueCat SDK: `getCustomerInfo`（サブスクリプション情報取得）
  - Supabase Auth: `signOut`（ログアウト）
  - Supabase Realtime: `openclaw_instances` テーブルサブスクリプション（ステータス監視）
  - Expo Push API: プッシュ通知送信（`send-push-notification` 経由）
  - Expo Notifications SDK: 通知権限リクエスト + Push Token 取得
