# 日記 + AI振り返り 仕様書

## 基本情報
- 担当Agent: Agent D (Engagement)
- 関連画面: app/(tabs)/history.tsx
- 依存する機能: 認証、課金（Pro限定）
- 依存される機能: 洞察（感情データ連携）

## 目的
Proユーザーが毎日の気持ちを記録し、AIが振り返りコメントを提供する。
日記を通じてユーザーの自己理解を促進し、AI分身との関係性を深めることでリテンション向上・チャーン低下につなげる。

## ユーザーストーリー
- [ ] Proユーザーとして、テキストと気分絵文字で日記を作成したい。なぜなら毎日の気持ちを手軽に記録したいから。
- [ ] Proユーザーとして、AIからの振り返りコメントを読みたい。なぜなら自分では気づけない視点を得たいから。
- [ ] Proユーザーとして、過去の日記を日付ごとに振り返りたい。なぜなら自分の感情の変化を把握したいから。
- [ ] Freeユーザーとして、日記機能の価値を理解してProにアップグレードしたい。なぜなら自分に合った機能かどうか確認したいから。

## 受け入れ条件（Acceptance Criteria）

### AC-1: Proユーザーが日記を作成できる（テキスト+気分）
- Given: Proサブスクリプションが有効なユーザーが日記タブを開いている
- When: 「+」ボタンをタップし、気分絵文字を選択し、テキストを入力して「保存」をタップする
- Then: 日記が `journal_entries` テーブルに保存され、日記一覧に新しいエントリが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| テキスト未入力で保存 | 保存ボタンが無効化（disabled）されている |
| 気分未選択で保存 | 保存ボタンが無効化（disabled）されている |
| テキストが3,000文字を超える | 入力が3,000文字で制限される（文字カウンター表示） |
| ネットワーク切断中に保存 | エラーメッセージ表示、入力内容は保持される |
| 保存中にアプリがバックグラウンドに移行 | バックグラウンド復帰後に保存完了を確認 |

#### テスト観点
- [ ] 正常系: テキスト+気分で日記が保存される
- [ ] 正常系: 保存後に日記一覧に即座に反映される
- [ ] 異常系: テキスト空欄では保存できない
- [ ] 異常系: 気分未選択では保存できない
- [ ] 境界値: テキスト1文字で保存できる
- [ ] 境界値: テキスト3,000文字で保存できる
- [ ] 境界値: テキスト3,001文字は入力できない

### AC-2: AI振り返りが自動生成される
- Given: Proユーザーが日記を保存した
- When: 保存処理が完了する
- Then: Supabase Edge Function `journal-reflect` が呼び出され、3〜5秒以内にAI振り返りコメントが `journal_entries.ai_reflection` に保存される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| Edge Function がタイムアウト | ローディング表示後「振り返りを生成できませんでした」と表示、リトライボタン表示 |
| Edge Function がエラーを返す | エラーログを記録し、日記本体は保存済みの状態を維持 |
| 非常に短い日記（数文字） | AIがコンテキストに応じた短い振り返りを生成する |
| 不適切な内容の日記 | AIが共感的な応答を返す（モデレーションはEdge Function側で処理） |

#### テスト観点
- [ ] 正常系: 保存後にAI振り返りが生成される
- [ ] 正常系: 振り返りが80〜150文字程度で生成される
- [ ] 異常系: Edge Functionエラー時に日記本体は保存済み
- [ ] 異常系: タイムアウト時にリトライ可能
- [ ] モック: Edge Functionのモックを使用してテスト

### AC-3: 日記一覧が日付グループで表示される
- Given: Proユーザーが複数の日記を作成済み
- When: 日記タブを開く
- Then: 日記が作成日時の降順で表示され、月ごとにセクション分けされている（例: 「2026年2月」）

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 日記が0件 | 空状態画面（「最初の日記を書いてみよう」メッセージ）を表示 |
| 日記が20件を超える | スクロール時に20件ずつ追加ロード（ページネーション） |
| 同月に複数件 | 同一セクション内に日付降順で表示 |
| 月をまたぐ日記 | 異なるセクションに正しくグルーピング |

#### テスト観点
- [ ] 正常系: 日記が降順で表示される
- [ ] 正常系: 月ごとにセクション分けされる
- [ ] 境界値: 日記0件で空状態が表示される
- [ ] 境界値: 20件ちょうどで追加ロードが発生しない
- [ ] 境界値: 21件目で追加ロードが発生する

### AC-4: 日記を展開してAI振り返りを読める
- Given: AI振り返りが生成済みの日記が一覧に表示されている
- When: 日記エントリをタップする
- Then: 日記詳細画面が開き、日記本文とAI振り返りコメントが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| AI振り返りがまだ生成中 | ローディングインジケーターを表示 |
| AI振り返りが未生成（エラーで失敗） | 「振り返りを生成」ボタンを表示 |
| 日記詳細画面から編集 | 編集モーダルが開き、本文・気分・タグを変更可能 |
| 日記詳細画面から削除 | 確認ダイアログ後に論理削除 |

#### テスト観点
- [ ] 正常系: タップで詳細画面が開く
- [ ] 正常系: AI振り返りが表示される
- [ ] 正常系: 編集・削除ボタンが動作する
- [ ] 異常系: 振り返り未生成時にリトライボタンが表示される

### AC-5: Freeユーザーにはアップグレード誘導が表示される
- Given: Freeプランのユーザーがアプリにログインしている
- When: 日記タブをタップする
- Then: 「日記はProの機能です」メッセージと「Proにアップグレード」ボタンが表示される。日記作成UIは表示されない

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| トライアル期間中のユーザー | Pro同様に日記機能を利用可能 |
| サブスクリプション期限切れ | Freeユーザーと同じアップグレード誘導を表示 |
| グレースピリオド中 | Pro同様に日記機能を利用可能 |
| 「Proにアップグレード」タップ | ペイウォール画面 (paywall)/index.tsx に遷移 |

#### テスト観点
- [ ] 正常系: Freeユーザーにアップグレード誘導が表示される
- [ ] 正常系: アップグレードボタンタップでペイウォールに遷移
- [ ] 正常系: トライアルユーザーは日記機能を利用可能
- [ ] 正常系: グレースピリオド中のユーザーは日記機能を利用可能
- [ ] 異常系: 期限切れユーザーにアップグレード誘導が表示される

### AC-6: プルダウンリフレッシュで最新データが取得される
- Given: Proユーザーが日記一覧を表示している
- When: 画面を下にプルダウンする
- Then: 最新の日記データがSupabaseから取得され、一覧が更新される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| リフレッシュ中にネットワークエラー | エラーメッセージ表示、既存データは保持 |
| リフレッシュ中に新しい日記が追加された | 新しい日記が一覧の先頭に表示される |
| 連続してリフレッシュ | デバウンス処理で過剰なAPIコールを防止 |

#### テスト観点
- [ ] 正常系: プルダウンで最新データが取得される
- [ ] 正常系: リフレッシュインジケーターが表示・非表示される
- [ ] 異常系: ネットワークエラー時に既存データが保持される
- [ ] 性能: 連続リフレッシュがデバウンスされる

## 画面仕様

### 日記一覧画面（journal.tsx）
- 入力項目: なし（表示のみ）
- 表示項目: 日記エントリ一覧（日付、気分アイコン、本文プレビュー50文字、タグ）、月ごとセクションヘッダー
- アクション: 「+」ボタンで日記作成モーダル表示、エントリタップで詳細画面遷移、プルダウンリフレッシュ
- 状態遷移: ローディング → 一覧表示 / 空状態 / エラー表示

### 日記作成モーダル
- 入力項目: 気分絵文字（5段階必須）、本文テキスト（1〜3,000文字必須）、タグ（任意）
- 表示項目: 気分選択UI、テキスト入力エリア、タグ選択UI（プリセット+カスタム）
- アクション: 保存、キャンセル
- 状態遷移: 入力中 → 保存中（ローディング） → 完了（モーダル閉じ）/ エラー

### 日記詳細画面
- 入力項目: なし（表示のみ）
- 表示項目: 日付、気分アイコン、本文全文、タグ、AI振り返りコメント
- アクション: 編集ボタン、削除ボタン、戻るボタン
- 状態遷移: ローディング → 表示 / AI振り返り生成中 / エラー

## データ仕様
- 使用するテーブル: `journal_entries`, `mood_records`
- 必要なAPI: Supabase Edge Function `journal-reflect`（AI振り返り生成）
- 連携: 日記作成時に `mood_records` テーブルにも気分を upsert
