# 日記機能（チャット統合）仕様書

## 基本情報

| 項目 | 内容 |
|------|------|
| 機能名 | 日記（Journal）— チャット統合版 |
| 担当Agent | Agent C (Core AI) — チャット機能の一部として実装 |
| 関連画面 | `app/(tabs)/index.tsx`（チャットタブ内） |
| 依存する機能 | チャット（`chat.md`）、認証、課金（Pro限定） |
| 依存される機能 | ツイン情報（気分データ連携） |
| 統合先 | `specs/features/chat.md` |

## 統合方針

日記機能は独立したタブではなく、**チャットタブに統合**。

**チャット履歴 = 日記履歴**（統合ビュー）。

- AIツインがチャット内で「今日はどうだった？」と定期的に聞く
- ユーザーの回答がジャーナルエントリーとして `journal_entries` テーブルに保存される
- 振り返り関連メッセージには📝バッジを表示し、通常チャットと視覚的に区別
- チャット履歴をスクロールすることで過去の振り返りも見返せる

### 独立タブを廃止した理由
1. **UXのシームレス化**: 日記を書くためだけに別タブに移動する摩擦を減らす
2. **エンゲージメント向上**: チャットとして会話的に振り返りを促すことで、継続率向上
3. **開発効率**: チャット機能内に統合することで実装・メンテナンスコストを削減
4. **AIツインとの一体感**: 「もう一人の自分」との会話の中で自然に日記が生まれる体験

## 日記エントリーの生成フロー

### 1. トリガー: AIツインが振り返りを促す

以下のいずれかの条件で、AIツインがチャット内で振り返りを促す:

| トリガー | 条件 |
|---------|------|
| 定期プロンプト | 最後のチャットから6時間以上経過（1日1回まで） |
| ユーザー開始 | ユーザーが「振り返りしたい」「日記書きたい」等のキーワードを入力 |
| 定時プッシュ通知 | 毎日22:00（ローカルタイム）にプッシュ通知（オプション設定で有効化） |

### 2. AIツインのプロンプトメッセージ

```json
{
  "role": "assistant",
  "content": "今日はどうだった？良かったこと、気になったこと、何でも教えて。",
  "metadata": {
    "isJournalPrompt": true
  }
}
```

- チャット画面に📝バッジを表示
- バブル背景色を薄いアクセントカラーに変更（視覚的区別）

### 3. ユーザーが回答

```json
{
  "role": "user",
  "content": "今日は仕事で大きな成果が出て嬉しかった。チームにも感謝されてやりがいを感じた。",
  "metadata": {
    "isJournalEntry": true,
    "journalEntryId": "uuid"
  }
}
```

- `chat_messages` テーブルに保存（通常のメッセージとして）
- **同時に `journal_entries` テーブルにも保存**:

```sql
INSERT INTO journal_entries (user_id, content, mood, created_at)
VALUES (auth.uid(), '[回答内容]', NULL, NOW())
RETURNING id;
```

- `mood` は NULL で保存（後から Twin Info 画面で記録可能）

### 4. AI振り返りコメントの生成

1. `journal-reflect` Edge Function を呼び出し:

```typescript
const response = await fetch('/functions/v1/journal-reflect', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${token}` },
  body: JSON.stringify({
    userId: user.id,
    journalContent: userMessage.content,
    conversationHistory: recentMessages.slice(-10), // 最近10件
  }),
});
```

2. Edge Function がAI振り返りコメントを生成（80〜150文字）

3. 生成された振り返りコメントを:
   - `chat_messages` に追加（`role: assistant`, `metadata.isJournalReflection: true`）
   - `journal_entries.ai_reflection` カラムに更新

```sql
UPDATE journal_entries
SET ai_reflection = '[振り返りコメント]'
WHERE id = '[journalEntryId]';
```

4. チャット画面にAI振り返りコメントが表示される

## ユーザーストーリー（INVEST準拠）

| ID | ストーリー | 優先度 |
|----|-----------|-------|
| US-1 | Proユーザーとして、チャット内でAIツインから「今日はどうだった？」と聞かれ、日記を記録したい。なぜなら別タブに移動する手間なく振り返りたいから。 | P1 |
| US-2 | Proユーザーとして、振り返り回答に対してAIツインから共感的なフィードバックをもらいたい。なぜなら一人で振り返るより気づきが得られるから。 | P1 |
| US-3 | Proユーザーとして、過去の振り返り履歴をチャット内でスクロールして見返したい。なぜなら自分の感情の変化を把握したいから。 | P2 |
| US-4 | Proユーザーとして、振り返りメッセージと通常チャットを視覚的に区別したい。なぜなら後で振り返りだけを見返したいから。 | P2 |
| US-5 | Freeユーザーとして、過去にProで作成した振り返り履歴を読み取り専用で閲覧したい。なぜなら自分の過去のデータにアクセスしたいから。 | P3 |

## 受け入れ条件（Acceptance Criteria）

### AC-1: Proユーザーがチャット内で振り返り会話を開始できる

- **Given:** Proサブスクリプションが有効で、最後のチャットから6時間以上経過している
- **When:** チャット画面を開く
- **Then:**
  1. AIツインから「今日はどうだった？」等の振り返り促進メッセージが表示される
  2. メッセージに📝バッジが表示される
  3. バブル背景色が薄いアクセントカラーになる
  4. `chat_messages` に `metadata.isJournalPrompt: true` で保存される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 既に当日1回振り返り済み | 再度促さない（1日1回まで） |
| ユーザーがプロンプトを無視 | 次回チャット時（6時間後）に再度促す |
| Freeユーザー | 振り返りプロンプトは表示されない（通常チャットのみ） |

#### テスト観点
- [ ] Proユーザー: 6時間経過後に振り返りプロンプトが表示される
- [ ] 1日1回制限: 同日2回目は表示されない
- [ ] Freeユーザー: 振り返りプロンプトが表示されない

---

### AC-2: 振り返り回答がジャーナルエントリーとして保存される

- **Given:** AIツインが振り返りを促し、ユーザーが回答を入力した
- **When:** 送信ボタンをタップする
- **Then:**
  1. `chat_messages` に `metadata.isJournalEntry: true` で保存される
  2. 同時に `journal_entries` テーブルに同じ内容が保存される
  3. `journal_entries.mood` は NULL で保存される（後から Twin Info で記録可能）
  4. チャット画面に📝バッジ付きでメッセージが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 回答が3,000文字を超える | 入力が3,000文字で制限される（文字カウンター表示） |
| 回答が1文字のみ | 保存される（最小文字数制限なし） |
| ネットワークエラーで保存失敗 | エラーメッセージ表示、入力内容は保持される |
| 回答が複数のメッセージに分かれる | 最初のメッセージのみがジャーナルエントリーとして保存される |

#### テスト観点
- [ ] 正常系: 回答が `chat_messages` と `journal_entries` 両方に保存される
- [ ] 境界値: 3,000文字で保存できる
- [ ] 境界値: 3,001文字は入力できない
- [ ] 異常系: ネットワークエラー時に入力内容が保持される

---

### AC-3: AI振り返りコメントが自動生成される

- **Given:** ユーザーが振り返り回答を送信した
- **When:** 送信処理が完了する
- **Then:**
  1. `journal-reflect` Edge Function が呼び出される
  2. 3〜5秒以内にAI振り返りコメント（80〜150文字）が生成される
  3. 振り返りコメントが `chat_messages` に `metadata.isJournalReflection: true` で保存される
  4. 振り返りコメントが `journal_entries.ai_reflection` カラムに更新される
  5. チャット画面に振り返りコメントが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| Edge Function がタイムアウト（10秒） | チャットに「振り返りを生成できませんでした」と表示、リトライボタン表示 |
| Edge Function がエラーを返す | エラーログを記録、ジャーナルエントリーは保存済みの状態を維持 |
| 非常に短い回答（数文字） | AIがコンテキストに応じた短い振り返りを生成する |
| 不適切な内容の回答 | AIが共感的な応答を返す（モデレーションは Edge Function 側で処理） |

#### テスト観点
- [ ] 正常系: AI振り返りコメントが生成される
- [ ] 正常系: 振り返りコメントが80〜150文字程度
- [ ] 異常系: Edge Function エラー時にジャーナルエントリーは保存済み
- [ ] 異常系: タイムアウト時にリトライ可能
- [ ] モック: Edge Function のモックを使用してテスト

---

### AC-4: 振り返りメッセージが通常チャットと視覚的に区別される

- **Given:** チャット画面に振り返り関連メッセージが表示されている
- **When:** チャット履歴をスクロールする
- **Then:**
  1. 振り返りプロンプト、ユーザー回答、AI振り返りコメントに📝バッジが表示される
  2. 振り返りメッセージのバブル背景色が薄いアクセントカラーになる
  3. 通常チャットメッセージは従来通りの背景色

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 振り返りと通常チャットが混在 | 各メッセージのタイプに応じてUIが切り替わる |
| 長い振り返りコメント | スクロール可能なバブル内で全文表示 |

#### テスト観点
- [ ] 正常系: 振り返りメッセージに📝バッジが表示される
- [ ] 正常系: 背景色が通常チャットと異なる
- [ ] 正常系: 通常チャットは従来通りの表示

---

### AC-5: 過去の振り返り履歴をチャット内で見返せる

- **Given:** Proユーザーが複数の振り返りを作成済み
- **When:** チャット画面を上方向にスクロールする
- **Then:**
  1. 過去の振り返りメッセージが時系列で表示される
  2. 50件ごとにページネーションで追加ロード
  3. 振り返りメッセージには📝バッジが表示される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 振り返りが0件 | 通常チャットのみ表示される |
| 振り返りのみフィルター表示（Phase 2） | フィルターボタンで振り返りメッセージのみ表示可能 |
| Pro→Freeダウングレード後 | 過去の振り返り履歴は読み取り専用で閲覧可能 |

#### テスト観点
- [ ] 正常系: 過去の振り返りが時系列で表示される
- [ ] 正常系: スクロールでページネーション動作
- [ ] 境界値: 50件ちょうどで追加ロードが発生しない
- [ ] 境界値: 51件目で追加ロードが発生する

---

### AC-6: Twin Info で気分を後から記録できる

- **Given:** ユーザーが振り返りを作成済み（`journal_entries.mood` が NULL）
- **When:** Twin Info 画面（`app/(tabs)/twin.tsx`）で気分を選択して保存
- **Then:**
  1. `journal_entries.mood` カラムが更新される
  2. チャット画面には反映されない（`journal_entries` のみ更新）
  3. Twin Info 画面の気分グラフに反映される

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 複数のジャーナルエントリーがある日 | 最新のエントリーの気分が更新される |
| 気分を複数回変更 | 最新の気分で上書きされる |

#### テスト観点
- [ ] 正常系: Twin Info で気分を記録すると `journal_entries.mood` が更新される
- [ ] 正常系: チャット画面には反映されない
- [ ] 正常系: Twin Info の気分グラフに反映される

### AC-7: Freeユーザーには振り返り機能が提供されない

- **Given:** Freeプランのユーザーがアプリにログインしている
- **When:** チャット画面を開く
- **Then:**
  1. AIツインから振り返りプロンプトは送信されない
  2. 通常チャット（初回10Kトークン制限、リセットなし）のみ利用可能
  3. 過去にProで作成した振り返り履歴は読み取り専用で閲覧可能

#### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| トライアル期間中 | Pro同様に振り返り機能を利用可能 |
| サブスクリプション期限切れ | Freeユーザーと同じ制限適用、過去の履歴は閲覧可能 |
| グレースピリオド中 | Pro同様に振り返り機能を利用可能 |

#### テスト観点
- [ ] 正常系: Freeユーザーに振り返りプロンプトが表示されない
- [ ] 正常系: 過去の振り返り履歴は閲覧可能
- [ ] 正常系: トライアルユーザーは振り返り機能を利用可能
- [ ] 正常系: グレースピリオド中は振り返り機能を利用可能

## データ仕様

### journal_entries テーブル

チャットから抽出されたジャーナルデータを保存。気分トラッキング・統計分析に使用。

| カラム | 型 | 説明 |
|--------|-----|------|
| id | uuid | PK |
| user_id | uuid | FK -> auth.users |
| content | text | ユーザーの振り返り回答（`chat_messages` から複製） |
| mood | text | 気分（nullable、後から Twin Info で記録可能）|
| ai_reflection | text | AIの振り返りコメント（80〜150文字） |
| created_at | timestamptz | 作成日時 |

**RLS ポリシー:** `user_id = auth.uid()` で本人のみアクセス可能。

### chat_messages のメタデータ拡張

```typescript
interface ChatMessageMetadata {
  isJournalPrompt?: boolean;      // AIがジャーナルを促すメッセージ
  isJournalEntry?: boolean;       // ユーザーのジャーナル回答
  isJournalReflection?: boolean;  // AIの振り返りコメント
  journalEntryId?: string;        // 対応する journal_entries.id
  // 既存フィールド
  toolExecutionResult?: any;
}
```

### Edge Function 連携

`supabase/functions/journal-reflect/index.ts` はチャット内でAIが振り返りを生成する際に内部的に呼び出される。

**入力:**
```json
{
  "userId": "uuid",
  "journalContent": "今日は仕事で成果が出て嬉しかった",
  "conversationHistory": [...] // 最近10件のチャット履歴
}
```

**出力:**
```json
{
  "reflection": "今日は成果が出て良かったね。達成感を感じられたのは、あなたの努力の証だよ。",
  "journalEntryId": "uuid"
}
```

## 画面仕様

### チャット画面（`app/(tabs)/index.tsx`）

日記機能はチャット画面内に統合。

#### 統合ビューの要素
- **通常チャットメッセージ**: 従来通りの背景色、バッジなし
- **振り返りプロンプト**: 📝バッジ、薄いアクセントカラー背景
- **ユーザーの振り返り回答**: 📝バッジ、薄いアクセントカラー背景
- **AI振り返りコメント**: 📝バッジ、薄いアクセントカラー背景

#### UI要素
- ヘッダー: AIツイン名 + 接続状態インジケーター
- メッセージ一覧: FlatList、下方向スクロール、最新メッセージが下
- 入力欄: TextInput + 送信ボタン、文字数カウンター（3,000文字制限）
- フィルターボタン（Phase 2）: 振り返りメッセージのみ表示

#### 状態遷移
1. **ローディング**: 履歴読み込み中
2. **通常表示**: チャット + 振り返りの統合ビュー
3. **振り返り生成中**: AI振り返りコメント生成中のローディングインジケーター
4. **エラー**: Edge Function エラー時のリトライボタン表示

## テスト観点

### 正常系
- [ ] Proユーザー: 6時間経過後に振り返りプロンプトが表示される
- [ ] 振り返り回答が `chat_messages` と `journal_entries` 両方に保存される
- [ ] AI振り返りコメントが生成され、チャットに表示される
- [ ] 振り返りメッセージに📝バッジが表示される
- [ ] 過去の振り返り履歴がスクロールで見返せる
- [ ] Twin Info で気分を記録すると `journal_entries.mood` が更新される

### 異常系
- [ ] Edge Function タイムアウト時にリトライボタンが表示される
- [ ] ネットワークエラー時に入力内容が保持される
- [ ] Edge Function エラー時にジャーナルエントリーは保存済み

### 境界値
- [ ] 振り返り回答 3,000文字で保存できる
- [ ] 振り返り回答 3,001文字は入力できない

### 権限
- [ ] Freeユーザー: 振り返りプロンプトが表示されない
- [ ] トライアルユーザー: 振り返り機能を利用可能

## 非機能要件

| 項目 | 要件 |
|------|------|
| AI振り返り生成時間 | 3〜5秒以内 |
| ジャーナルエントリー保存 | 送信後1秒以内に `journal_entries` に保存 |
| 振り返りプロンプト頻度 | 1日1回まで（最後のチャットから6時間以上経過時） |
| 文字数制限 | ユーザー回答 3,000文字、AI振り返りコメント 80〜150文字 |
| 履歴表示件数 | 初回50件、スクロールで50件ずつ追加ロード |
