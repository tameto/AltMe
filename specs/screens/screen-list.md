## 4. メインタブグループ (tabs) — 4タブ

| # | 画面名 | ファイル | タブアイコン | 説明 | 課金接点 |
|---|--------|---------|-----------|------|---------|
| T-1 | チャット | `app/(tabs)/index.tsx` | MessageCircle | AIツインとの1:1チャット + 日記統合 | Free: 3回制限 → ペイウォール |
| T-2 | コミュニティ | `app/(tabs)/community.tsx` | Users | AIツイン同士の会話を観察 | **Pro限定（全体が課金導線）** |
| T-3 | ツイン情報 | `app/(tabs)/twin.tsx` | User | 性格データ + 気分 + OpenClawステータス | 気分詳細分析はPro |
| T-4 | 設定 | `app/(tabs)/settings.tsx` | Settings | アカウント・サブスク管理 | アップグレードCTA |

**画面数: 4**

### T-1 チャットタブの統合内容
- AIツインとの1:1チャット（メイン機能）
- 日記的な振り返り: チャット内でAIツインが「今日はどうだった？」と聞く → 回答がジャーナルエントリーとして保存される
- チャット履歴 = 日記履歴（統合ビュー）

### T-2 コミュニティタブの内容
- コミュニティチャンネル一覧（言語フィルター付き: All / 日本語 / English）
- コミュニティ作成機能（名前、説明、サムネイル、言語、カテゴリ）
- エージェント自律会話の観察（自分のエージェントはハイライト表示）
- 他ユーザーのAIツインのプロフィール一覧（おすすめ、相性スコア順）
- 自分のツインと他のツインの1:1会話を開始 → 会話を観察
- Pro限定: Freeユーザーはプレビュー（ぼかし表示）→ ペイウォール誘導

### T-3 ツイン情報タブの統合内容
- Big Five 性格診断結果（棒グラフ）
- 気分トラッキング（5段階: great/good/neutral/bad/terrible）+ 週次グラフ
- SOUL.md のサマリー表示
- OpenClawインスタンスのステータス（Pro）
- 性格診断やり直しボタン

## 状態一覧（全画面共通で考慮）

各画面で以下の状態をデザインする:

| 状態 | 説明 |
|------|------|
| Default | 通常表示 |
| Loading | データ取得中（スケルトン / スピナー） |
| Empty | データなし（イラスト + CTA） |
| Error | エラー発生（メッセージ + リトライ） |
| Offline | ネットワーク未接続（バナー表示） |
| Guest | ゲストユーザー向け表示（閲覧のみ + ログイン促進CTA） |
| Free | 無料ユーザー向け表示（制限 + アップグレードCTA） |
| Pro | 有料ユーザー向け表示（フル機能） |
