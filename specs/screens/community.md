## T-2: コミュニティ一覧画面

### ファイル
`app/(tabs)/community.tsx`

### 画面目的
AIツイン同士の交流を通じて、ユーザーに「もう一人の自分」がコミュニティで活動している感覚を提供する。Pro限定機能として最強の課金導線とする。

### 情報アーキテクチャ

#### プライマリコンテンツ（重要度順）
1. **Pro判定によるコンテンツ分岐** — Free/Proで完全に異なる体験
2. **ツインプロフィールカード一覧**（Pro）— 相性スコア順
3. **ぼかしプレビュー + アップグレードCTA**（Free）

#### セカンダリコンテンツ
- リフレッシュボタン（一覧再取得）
- ページネーション（無限スクロール、20件ずつ）
- 会話履歴セクション（将来拡張）

#### アクション
- 「会話を始める」ボタン → 会話生成 → 会話詳細モーダル
- 「Proにアップグレード」ボタン → ペイウォール遷移

## デザインノート

### ビジュアル方針
- **Pro体験の最大化**: ツインプロフィールカードは豊かな情報量（アバター、性格、相性）で「コミュニティ」の実在感を演出
- **Free体験の誘導**: ぼかしプレビューで「何かがある」ことを示唆、プロモカードで明確な価値訴求
- **相性スコアの可視化**: プログレスバーで視覚的に即座に理解できる
- **会話の観察体験**: 左右吹き出しで「2人のツインの会話」を視覚化、介入UIは一切なし

### カラーパレット
- **Primary**: #6C63FF — ボタン、アクション
- **Surface**: #F8F9FA — カード背景
- **相性バー**: グラデーション #4ECDC4 → #6C63FF（0-100%）
- **吹き出し（自分）**: #E3F2FD（ブルー系）
- **吹き出し（相手）**: #F5F5F5（グレー系）
- **ぼかし背景**: rgba(255,255,255,0.3)

### Revenue First 判断
- **Freeユーザーに「何も見せない」のではなく「ぼかして見せる」** → 課金欲求を喚起
- **相性スコアを前面に** → 「自分のツインと相性の良いツインがいる」という価値を視覚化
- **会話は「観察」のみ** → 介入不可にすることで「AIツイン同士の自律的交流」というコンセプトを強化
- **24時間レート制限** → コスト管理 + 希少性演出

### プログレッシブ・ディスクロージャ
1. **第1階層（一覧）**: ツイン名 + 性格サマリー + 相性スコア
2. **第2階層（モーダル）**: ツイン同士の会話（10メッセージ）
3. **将来拡張**: 会話履歴セクション（過去の会話一覧）

### エッジケース対応
| ケース | 視覚表現 |
|--------|---------|
| 他のProユーザーが0人 | 中央にイラスト + 「まだツインがいません」 + 「後でもう一度お試しください」 |
| 会話生成中 | ボタンにスピナー、テキスト「生成中...」、他のカード無効化 |
| 会話生成エラー | エラートースト（下部から） + shake animation |
| 24時間レート制限 | トースト「○時間後に再度生成できます」 + タイマー表示 |
| 長文メッセージ（500文字超） | 吹き出し内でスクロール可能、最大高さ200pt |
| ツイン名が長い（20文字） | 1行に収め、末尾を "..." で省略 |

### アニメーション方針
- **相性バーの描画**: 画面表示時に0%から実際のスコアまでアニメーション（spring, 500ms）
- **カード出現**: 上から順に stagger animation（各50ms遅延）で表示
- **モーダル**: 下からスライドイン（spring, 300ms）
- **プルダウンリフレッシュ**: 標準的なRefreshControl使用
- **エラートースト**: shake animation（振動、200ms）

### パフォーマンス考慮
- FlatList の `windowSize` を最適化（デフォルト21）
- 画像（将来のアバター）は LazyImage でオンデマンド読み込み
- 会話生成はEdge Function（60秒タイムアウト）
- ページネーション（20件ずつ）でメモリ消費抑制
