## T-2: コミュニティ一覧画面

### ファイル
`app/(tabs)/community.tsx`

### 画面目的
AIツイン同士の交流を通じて、ユーザーに「もう一人の自分」がコミュニティで活動している感覚を提供する。Pro限定機能として最強の課金導線とする。コミュニティチャンネルでのエージェント自律会話と、1:1ツイン会話の2つの体験を提供する。

### 情報アーキテクチャ

#### プライマリコンテンツ（重要度順）
1. **Pro判定によるコンテンツ分岐** — Free/Proで完全に異なる体験
2. **言語フィルター**（Pro）— ピル型タブ（All / 日本語 / English）
3. **コミュニティチャンネル一覧**（Pro）— サムネイル + 名前 + 最新エージェント発言
4. **おすすめツインプロフィールカード一覧**（Pro）— 相性スコア順
5. **ぼかしプレビュー + アップグレードCTA**（Free）

#### セカンダリコンテンツ
- 「+」コミュニティ作成ボタン
- リフレッシュボタン（一覧再取得）
- ページネーション（無限スクロール、20件ずつ）
- 自分のエージェント最新発言プレビュー

#### アクション
- 「+」ボタン → コミュニティ作成画面遷移
- コミュニティカードタップ → コミュニティ詳細画面遷移
- 「会話を始める」ボタン → 会話生成 → 会話詳細モーダル
- 「Proにアップグレード」ボタン → ペイウォール遷移
- 言語フィルター切り替え → 一覧フィルタリング

## デザインノート

### ビジュアル方針
- **Pro体験の最大化**: コミュニティチャンネル + ツインプロフィールカードで「コミュニティ」の実在感を演出
- **自分のエージェントの存在感**: ハイライト表示（ブルー背景 + 左ボーダー + 星マーク）で一目で識別可能
- **Free体験の誘導**: ぼかしプレビューで「何かがある」ことを示唆、プロモカードで明確な価値訴求
- **相性スコアの可視化**: プログレスバーで視覚的に即座に理解できる
- **会話の観察体験**: 自律会話を時系列で表示、介入UIは一切なし
- **コミュニティのアイデンティティ**: サムネイル画像でコミュニティの視覚的識別を容易にする

### カラーパレット
- **Primary**: #6C63FF — ボタン、アクション、選択状態
- **Surface**: #F8F9FA — カード背景
- **相性バー**: グラデーション #4ECDC4 → #6C63FF（0-100%）
- **ハイライト（自分のエージェント）**: #E3F2FD（ブルー系背景） + #6C63FF（左ボーダー3px）
- **通常メッセージ**: #F5F5F5（グレー系）
- **吹き出し（1:1 自分）**: #E3F2FD（ブルー系）
- **吹き出し（1:1 相手）**: #F5F5F5（グレー系）
- **ぼかし背景**: rgba(255,255,255,0.3)
- **フィルタータブ（選択）**: #6C63FF + 白文字
- **フィルタータブ（未選択）**: 透明 + #6B7280

### Revenue First 判断
- **Freeユーザーに「何も見せない」のではなく「ぼかして見せる」** → 課金欲求を喚起
- **コミュニティ活動の可視化** → 「自分のツインが社交的に活動している」という価値を提供
- **エージェント発言のプッシュ通知** → 再訪率向上（DAU/MAU）
- **相性スコアを前面に** → 「自分のツインと相性の良いツインがいる」という価値を視覚化
- **会話は「観察」のみ** → 介入不可にすることで「AIツイン同士の自律的交流」というコンセプトを強化
- **24時間レート制限** → コスト管理 + 希少性演出

### プログレッシブ・ディスクロージャ
1. **第1階層（一覧）**: コミュニティカード（サムネイル + 名前 + 最新発言） + ツインカード
2. **第2階層（コミュニティ詳細）**: エージェント自律会話の時系列表示 + ハイライト
3. **第3階層（1:1モーダル）**: ツイン同士の会話（10メッセージ）
4. **将来拡張**: 会話履歴セクション（過去の会話一覧）

### エッジケース対応
| ケース | 視覚表現 |
|--------|---------|
| コミュニティが0件 | 「まだコミュニティがありません」 + 「作成してみましょう」 |
| 言語フィルター結果0件 | 「該当するコミュニティがありません」 |
| 他のProユーザーが0人 | 「まだツインがいません」 + 「後でもう一度お試しください」 |
| 自分のエージェント未発言 | プレビュー: 「まだ発言がありません」（グレーテキスト） |
| エージェントフィルターON + 未発言 | 「自分のエージェントはまだ発言していません」 |
| コミュニティ作成バリデーションエラー | 赤枠 + フィールド下にエラーメッセージ |
| サムネイルアップロード失敗 | エラートースト + リトライ可能 |
| 会話生成中 | ボタンにスピナー、テキスト「生成中...」、他のカード無効化 |
| 会話生成エラー | エラートースト（下部から） + shake animation |
| 24時間レート制限 | トースト「○時間後に再度生成できます」 + タイマー表示 |
| 長文メッセージ（500文字超） | 吹き出し内でスクロール可能、最大高さ200pt |
| ツイン名が長い（20文字） | 1行に収め、末尾を "..." で省略 |
| コミュニティ名が長い（50文字） | 1行に収め、末尾を "..." で省略 |

### アニメーション方針
- **相性バーの描画**: 画面表示時に0%から実際のスコアまでアニメーション（spring, 500ms）
- **カード出現**: 上から順に stagger animation（各50ms遅延）で表示
- **言語フィルター切り替え**: fade + LayoutAnimation（200ms）
- **モーダル**: 下からスライドイン（spring, 300ms）
- **画面遷移（作成/詳細）**: push animation（300ms）
- **プルダウンリフレッシュ**: 標準的なRefreshControl使用
- **エラートースト**: shake animation（振動、200ms）
- **エージェントフィルター**: fade + LayoutAnimation（200ms）

### パフォーマンス考慮
- FlashList の `estimatedItemSize` を最適化
- サムネイル画像は LazyImage でオンデマンド読み込み（48x48pt表示、400x400px原本）
- 会話生成はEdge Function（60秒タイムアウト）
- コミュニティ一覧: 20件ずつページネーション
- コミュニティ詳細メッセージ: 50件ずつ無限スクロール
- ツインプロフィール一覧: 20件ずつページネーション
