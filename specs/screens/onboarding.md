## O-2: 性格診断画面

### ファイル
`app/(onboarding)/personality-quiz.tsx`

### 目的

質問は簡潔で直感的に、回答体験をストレスフリーに保つ。

```
┌─────────────────────────────────┐
│          SafeArea Top           │
│                                 │
│  ← [戻る]          質問 1/5     │
│                                 │
│  ════════════════════════════   │
│  (Progress Bar: 20% filled)     │
│                                 │
│                                 │
│   あなたは新しいアイデアや経験に  │
│   オープンですか？               │
│                                 │
│                                 │
│  ┌─────────────────────────────┐│
│  │  とてもそう思う               ││
│  └─────────────────────────────┘│
│                                 │
│  ┌─────────────────────────────┐│
│  │  まあそう思う                 ││
│  └─────────────────────────────┘│
│                                 │
│  ┌─────────────────────────────┐│
│  │  あまりそう思わない            ││
│  └─────────────────────────────┘│
│                                 │
│  ┌─────────────────────────────┐│
│  │  全くそう思わない              ││
│  └─────────────────────────────┘│
│                                 │
│                                 │
│          SafeArea Bottom        │
└─────────────────────────────────┘
```

### コンポーネント構成

| # | コンポーネント | 種類 | 配置 | 備考 |
|---|--------------|------|------|------|
| 1 | BackButton | Button | 左上 | アイコンのみ、タップ領域44pt以上 |
| 2 | QuestionCounter | Text | 右上 | "質問 1/5" Caption 14pt |
| 3 | ProgressBar | View | ヘッダー下 | 高さ4pt、紫グラデーション |
| 4 | QuestionText | Text | 中央上 | 質問文 Title 20pt SemiBold、中央揃え |
| 5 | OptionCard (x4) | Pressable | 中央 | 選択肢カード、高さ56pt |

### スペーシング

| 区間 | 間隔 |
|------|------|
| SafeArea上端 → 戻るボタン | 8pt |
| 戻るボタン下端 → プログレスバー | 16pt |
| プログレスバー → 質問テキスト | 40pt |
| 質問テキスト → 最初の選択肢 | 32pt |
| 選択肢間 | 12pt |
| 最後の選択肢 → SafeArea下端 | 32pt |
| 左右マージン | 24pt |

### 選択肢カード仕様

| 要素 | 幅 | 高さ | 角丸 | スタイル |
|------|-----|------|------|---------|
| OptionCard (未選択) | fill - 48pt margin | 56pt | 12pt | 背景 #F8F9FA、テキスト #1A1A2E、border 1pt #E0E0E0 |
| OptionCard (選択済) | 同上 | 同上 | 同上 | 背景 #6C63FF、テキスト #FFFFFF、border なし |
| OptionCard (タップ中) | 同上 | 同上 | 同上 | scale(0.98) |

### 状態設計

| 状態 | 表示内容 |
|------|---------|
| **Default** | 質問 + 4つの選択肢表示、選択なし |
| **OptionSelected** | 選択した選択肢がハイライト（紫背景）、0.5秒後に次の質問へ自動遷移 |
| **BackNavigation** | 前の質問に戻る、以前の回答が選択状態で表示 |
| **Loading (5問目回答後)** | 「あなたの性格を分析中...」+ スピナー |
| **Error (分析失敗)** | エラーメッセージ + リトライボタン |
| **Offline** | オフラインバナー表示（回答はローカル保存、分析は接続後） |

### インタラクション

| アクション | 動作 | アニメーション |
|-----------|------|------------|
| 選択肢タップ | カードハイライト、0.5秒後に次の質問へ | カード背景色変化 (200ms)、画面 slide left (300ms) |
| 戻るボタンタップ | 前の質問に戻る、1問目なら welcome.tsx に戻る | 画面 slide right (300ms) |
| 5問目回答完了 | Edge Function `personality-analyze` 呼び出し、result.tsx へ遷移 | スピナー表示 → fade out → 結果画面 fade in |
| 分析エラー時 | エラーメッセージ + リトライボタン表示 | shake animation |

### アクセシビリティ

| 要素 | accessibilityLabel | accessibilityRole | accessibilityHint |
|------|-------------------|-------------------|------------------|
| BackButton | "戻る" | button | "前の質問に戻ります" |
| QuestionCounter | 自動読み上げ | text | — |
| ProgressBar | "進捗 20%" | progressbar | — |
| QuestionText | 自動読み上げ | header | — |
| OptionCard | 選択肢テキスト | button | "選択して次に進む" |

### Free / Pro 差分
なし（オンボーディング段階では課金状態に依存しない）

│                                 │

│                                 │

| # | コンポーネント | 種類 | 配置 | 備考 |

| 区間 | 間隔 |

### 名前入力フィールド仕様

| 要素 | 幅 | 高さ | 角丸 | スタイル |
|------|-----|------|------|---------|
| NameInput | fill - 48pt margin | 56pt | 12pt | 背景 #F8F9FA、テキスト中央揃え、Body 18pt |

### メッセージバブル仕様

| 要素 | 最大幅 | 角丸 | スタイル |
|------|--------|------|---------|
| AI メッセージ | 70% | 16pt | 背景 #F0EFFF（薄紫）、テキスト #1A1A2E、左揃え |
| User メッセージ | 70% | 16pt | 背景 #6C63FF、テキスト #FFFFFF、右揃え |
| パディング | — | — | 縦12pt、横16pt |

### ボタン仕様

| ボタン | 幅 | 高さ | 角丸 | スタイル |
|--------|-----|------|------|---------|
| 決定 | fill - 48pt margin | 56pt | 16pt | Primary背景 #6C63FF、白文字 |

### 状態設計

| 状態 | 表示内容 |
|------|---------|
| **NameEntry** | 名前入力フィールド + 決定ボタン表示、チャットエリア非表示 |
| **NameEntryInvalid** | 決定ボタン非活性（空文字または21文字以上） |
| **ChatActive** | チャットエリア表示、名前入力非表示、残り回数表示 |
| **AITyping** | AI応答中、タイピングインジケーター表示（3点アニメーション） |
| **ChatComplete** | 3往復完了、入力フィールド非活性、はじめるボタン表示 |
| **Loading** | Edge Function呼び出し中、スピナー表示 |
| **Error** | AIメッセージ送信失敗、リトライボタン表示 |
| **Offline** | オフラインバナー表示、送信ボタン非活性 |

### インタラクション

| AI応答エラー時 | エラーメッセージ + リトライボタン | shake animation |

### チャット往復数カウントロジック

- **1往復** = AIメッセージ1回 + Userメッセージ1回
- **初回**: AI自動メッセージ（「はじめまして！[名前]です。あなたのことをもっと知りたいな。今日はどんな一日でしたか？」）
- **2往復目**: Userが返信 → AI応答
- **3往復目**: Userが返信 → AI応答 → 「もっとあなたのこと知りたいな...また話そう？」（課金誘導）
- **完了**: はじめるボタン表示

## デザインノート

### ビジュアル方針
- **一貫性**: 全画面で紫→青グラデーションテーマを維持
- **ミニマリズム**: 各画面1つの明確なアクション、ノイズを排除
- **ストーリーテリング**: ウェルカム → 診断 → 結果 → 対面の自然な流れ
- **マイクロインタラクション**: 選択肢のハイライト、バーのアニメーション、吹き出しのスライドイン

### Revenue First 判断
- **O-3 詳細ブラー**: 課金導線の第1トリガー。「自分のことをもっと知りたい」欲求を刺激
- **O-4 チャット制限**: 課金導線の第2トリガー。「もっと話したい」欲求を高めてペイウォールへ誘導
- **Day 0 課金導線**: オンボーディング完了まで約8分、ユーザーの期待と欲求が最高潮の状態でペイウォールに到達

### エラーハンドリング

| エラーケース | 表示 | リカバリー |
|------------|------|-----------|
| Edge Function タイムアウト (30秒以上) | 「分析に時間がかかっています」+ リトライボタン | 再呼び出し |
| Edge Function 500エラー | 「分析に失敗しました」+ リトライボタン | ローカル簡易スコア計算にフォールバック |
| ネットワーク未接続 | オフラインバナー + ローカル保存 | 接続回復時に自動送信 |
| AI応答エラー | 「返信の取得に失敗しました」+ リトライボタン | 再呼び出し |
| DB保存失敗 | ログのみ（UX損なわない）、ローカル一時保存 | 次回起動時にリトライ |

### Offline 対応

| 画面 | Offline時の動作 |
|------|---------------|
| O-1 Welcome | 次に進めることを示すバナー表示 |
| O-2 Quiz | 回答をローカル保存、分析は接続回復後 |
| O-3 Result | ローカル簡易スコア計算で表示、Edge Function は接続回復後 |
| O-4 Meet Twin | メッセージ送信不可、オフラインバナー表示 |

### パフォーマンス最適化

- Big Five棒グラフ: React Native Reanimated で GPU アニメーション
- チャットメッセージ: FlashList で仮想化（将来の拡張時）
- 画像: SVG または Lottie でベクター形式
- Edge Function: タイムアウト30秒、リトライ3回まで
- ローカル状態: Zustand で管理、DB保存は非同期

## 実装ノート

### 使用するコンポーネント
- `SafeAreaView` — 全画面で使用
- `Pressable` — ボタン、選択肢カード
- `TextInput` — 名前入力、メッセージ入力
- `FlatList` / `FlashList` — チャットメッセージリスト（O-4）
- `Reanimated` — 棒グラフアニメーション（O-3）、画面遷移
- `react-native-blur` — 詳細分析ブラー（O-3、iOS標準ブラー）

### Edge Functions
- `personality-analyze` — Big Five分析 + サマリー生成
- `onboarding-chat` — 初回チャット応答（OpenAI API経由、GPT-4o-mini）

### Zustand Store
```typescript
interface OnboardingState {
  // O-2 Quiz
  quizAnswers: number[]; // 0-3 の配列（5問分）
  currentQuestion: number; // 0-4

  // O-3 Result
  personalityResult: {
    openness: number;
    conscientiousness: number;
    extraversion: number;
    agreeableness: number;
    neuroticism: number;
    summary: string;
  } | null;

  // O-4 Meet Twin
  twinName: string;
  chatMessages: Array<{ role: 'ai' | 'user'; content: string }>;
  remainingChatCount: number; // 3 → 2 → 1 → 0

  // Actions
  setQuizAnswer: (index: number, answer: number) => void;
  setCurrentQuestion: (index: number) => void;
  setPersonalityResult: (result: PersonalityResult) => void;
  setTwinName: (name: string) => void;
  addChatMessage: (message: { role: 'ai' | 'user'; content: string }) => void;
  decrementChatCount: () => void;
  resetOnboarding: () => void;
}
```

### データフロー
```
O-2 Quiz
  → quizAnswers を Zustand に保存
  → 5問目回答後、Edge Function `personality-analyze` 呼び出し
  → 結果を Zustand + `personality_results` テーブルに保存
  → O-3 Result へ遷移

O-3 Result
  → Zustand から personalityResult を取得
  → 棒グラフアニメーション表示
  → 「次へ」タップで O-4 へ遷移

O-4 Meet Twin
  → twinName を入力・確定
  → `profiles.twin_name` に保存
  → 初回チャット3往復
  → Edge Function `onboarding-chat` で AI応答取得
  → 3往復完了後、「はじめる」タップ
  → `profiles.onboarding_completed = true` に更新
  → ペイウォール画面へ遷移
```

### 境界値テスト
- 名前: 0文字（非活性）、1文字（OK）、20文字（OK）、21文字（制限）
- Big Fiveスコア: 0点、50点、100点
- チャット往復: 1/3、2/3、3/3（完了）

### セキュリティ
- 名前入力: サニタイズ（制御文字削除）
- Edge Function: RLS で user_id 検証
- チャットメッセージ: XSS対策（React Native は自動エスケープ）
