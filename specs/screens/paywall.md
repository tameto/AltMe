## デザインノート

### ビジュアル方針（Revenue First）
- **フルスクリーン課金画面** — アプリのMVP実装で最も重要な収益化ポイント
- **アンカリング効果** — 年額を最初に提示して月額を安く見せる。初回限定オファーで通常価格をアンカリング
- **FOMO（機会損失回避）** — カウントダウンタイマーで緊急性を演出、「この価格は初回のみ」バッジで限定感
- **視覚階層** — 年額プランに「推奨」バッジ + 紫色ボーダーで最も目立たせる
- **社会的証明** — Pro機能リストで価値を明確化（無制限チャット、コミュニティ、詳細分析）
- **低い認知負荷** — プランは最大3つまで。選択肢を絞って迷わせない
- **トライアル訴求** — 「3日間無料トライアル」を各プランカードに明示してリスク低減

### カラー使用
- **初回限定カード背景**: グラデーション（#FFD700 → #FF8C00、金→オレンジ）
- **初回限定テキスト**: #FFFFFF（白文字）
- **年額カードボーダー**: #6C63FF（Primary、2pt）
- **月額カードボーダー**: #E0E0E0（グレー、1pt）
- **割引テキスト**: #10B981（緑、Success）
- **機能リストチェック**: #4ECDC4（Secondary）

### タイポグラフィ使用
- **メイン見出し**: Display 28pt Bold、#1A1A2E
- **サブ見出し**: Body 16pt Regular、#6B7280
- **プラン価格**: Heading 22-24pt Bold、#1A1A2E
- **割引・トライアル**: Caption 14pt Regular、#10B981 / #6B7280
- **カウントダウン**: Heading 20pt Bold、#FFFFFF
- **機能リスト**: Body 16pt Regular、#1A1A2E

### 初回限定オファー表示ロジック
- 表示条件:
  1. `profiles.created_at` から24時間以内
  2. かつ過去に一度もProプランを購入していない（`subscriptions` テーブルで判定）
- カウントダウン計算: `24時間 - (現在時刻 - profiles.created_at)`
- タイマー更新頻度: 1秒ごと
- 期限到達時: 初回限定カードをfade out、年額・月額の2プランのみ表示

### Apple審査基準準拠
- **閉じるボタン必須** — フルスクリーンペイウォールでもユーザーが課金せずに閉じられること（App Store Review Guideline 3.1.1）
- **閉じるボタンサイズ**: 44x44pt（タップターゲット最小サイズ）
- **配置**: 右上、10pt × アイコン、グレー、目立ちすぎない（課金を邪魔しない）が認識可能
- **価格の明示**: すべてのプランで価格、期間、トライアル条件を明記
- **自動更新の明示**: 法的リンクで利用規約・プライバシーポリシーへのアクセス提供

### Revenue First 判断
- **オンボーディング直後に表示** — ユーザーが最も価値を感じた直後（ツイン対面後）に課金促進
- **初回限定オファーで最大化** — 50%OFFで初期LTV最大化、24時間限定で緊急性
- **年額プランを推奨** — LTV向上、チャーン率低減、ユーザー体験の継続性
- **トライアル訴求** — 3日間無料トライアルで心理的障壁を下げ、CVR向上
- **Pro機能リストで価値訴求** — 無制限チャット、コミュニティ、詳細分析で明確なベネフィット提示

### 状態遷移フロー
```
[Default (初回限定あり)]
     |
     ├─ カウントダウン終了
     │  └→ [Default (通常)]
     |
     ├─ プランカードタップ
     │  └→ [Loading (購入処理中)]
     |       |
     |       ├─ 購入成功 → [Success] → チャット画面（Pro）
     |       ├─ 購入失敗 → [Error] → リトライボタン表示
     |       └─ 購入キャンセル → [Default] に戻る
     |
     └─ 閉じるボタンタップ
        └→ チャット画面（Free）
```

### パフォーマンス考慮
- カウントダウンタイマー: setInterval 1秒更新、メモリリーク防止でクリーンアップ必須
- プランカードのpress state: transform使用（opacity + scale 0.98）
- スクロール: プラン数が多い場合（将来拡張）はScrollView、現在は固定レイアウト
- アニメーション: prefers-reduced-motion 考慮、カウントダウンはテキスト更新のみ

### テスト観点
- [ ] 初回限定オファー: 24時間以内のユーザーに表示される
- [ ] カウントダウンタイマー: リアルタイム更新、期限到達でカード非表示
- [ ] プラン選択: RevenueCat購入フロー正常動作
- [ ] 購入成功: チェックマーク → チャット画面遷移
- [ ] 購入失敗: エラーメッセージ + リトライボタン
- [ ] 閉じるボタン: Freeチャット画面に遷移
- [ ] 法的リンク: in-app browser で開く
- [ ] 境界値: 24時間ちょうどの表示切り替え
- [ ] アクセシビリティ: VoiceOver で全操作可能

### エッジケース
| ケース | 期待される動作 |
|--------|--------------|
| 24時間ちょうどの境界値 | サーバー側の `profiles.created_at` で判定、タイムゾーン考慮 |
| 端末時刻を手動変更 | サーバー時刻基準のため影響なし |
| 過去に課金→解約→再登録 | 初回限定オファー非表示（一度でも課金履歴があれば除外） |
| 購入処理中にアプリクローズ | 次回起動時にRevenueCat restorePurchases()で復元 |
| ネットワークエラー | オフラインバナー表示、プランカード無効化 |
| 複数デバイスで同時課金 | RevenueCat側でトランザクション管理、重複課金防止 |
| Pro購入済みユーザーが閉じた後再アクセス | ペイウォール非表示（`isPro === true`でルーティングガード）|
