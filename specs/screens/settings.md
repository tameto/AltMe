| **Default (Pro)** | プロフィール + Proプラン詳細 + OpenClawステータス（running） |

| **OpenClaw Running** | ステータス: 緑色バッジ「稼働中」、再起動ボタン非活性 |
| **OpenClaw Error** | ステータス: 赤色バッジ「エラー」+ エラーメッセージ、再起動ボタン活性化 |
| **OpenClaw Stopped** | ステータス: グレーバッジ「停止中」、再起動ボタン非活性 |
| **Offline** | 画面上部にオフラインバナー「ネットワークに接続してください」 |

## デザインノート

### ビジュアル方針
- **セクション分割**: 機能ごとにカードで分離し、視覚的階層を明確化
- **ステータスバッジ**: 色で一目でわかるステータス表示（緑=稼働、黄=セットアップ、赤=エラー、グレー=停止）
- **Pro限定セクション**: OpenClawインスタンス管理はProユーザーのみ表示し、価値を差別化
- **デストラクティブアクション**: アカウント削除は赤色で視覚的警告、確認フロー必須
- **スペーシング**: 各セクション間に24ptの余白でリズム感を出す

### Revenue First 判断
- **Freeユーザー向けCTA**: サブスクリプションセクションに「Proにアップグレード」を目立つ位置に配置
- **Pro価値の可視化**: OpenClawインスタンス管理という「インフラレベルの機能」を見せることで、Proの価値を強調
- **解約防止フロー**: サブスク管理画面で解約ボタンタップ時に、AI分身が蓄積したデータ量（チャット数、日記数）を表示し、損失感を訴求
- **アカウント削除の明示**: Apple審査要件対応として、設定画面内で容易に見つかる位置に配置

### OpenClawインスタンス管理の機能分担
- **設定画面**: ステータス表示 + 再起動操作 + エラーメッセージ
- **ツイン情報タブ (T-3)**: ステータス概要のみ表示（操作なし）
- **役割分離**: 管理操作は設定画面、情報参照はツイン情報タブ

### 状態遷移フロー

```
プロフィール編集:
[Default] → [フィールドタップ] → [編集モード]
         → [保存タップ] → [Loading] → [成功トースト] → [Default]
                                   ↘ [Error表示] → [Default]

OpenClawインスタンス再起動:
[Status: Error] → [再起動タップ] → [確認ダイアログ]
                → [確定] → [Status: Provisioning (スピナー)]
                         → [30s〜120s後] → [Status: Running (成功トースト)]
                                        ↘ [タイムアウト] → [Status: Error (エラー表示)]

アカウント削除:
[設定画面] → [アカウント削除タップ] → [M-3モーダル表示]
          → [「削除」入力] → [削除ボタン活性化]
          → [削除確定タップ] → [削除処理中 (スピナー)]
          → [完了] → [ログイン画面遷移]
                  ↘ [エラー] → [エラー表示 + サポート案内]
```

### アクセシビリティ考慮点
- 全ての入力フィールドにaccessibilityLabelとHintを設定
- ステータスバッジは色だけでなくテキストでも状態を明示
- 通知トグルはVoiceOverで「オン」「オフ」を読み上げ
- アカウント削除ボタンは「危険な操作」として明確にラベル付け
- タップターゲットは全て44pt以上を確保
