### 状態設計

| 状態 | 表示内容 |
|------|---------|
| **Default (Free)** | ヘッダー + メッセージ一覧 + 入力バー + 残り回数バッジ（2/3） |
| **Default (Pro)** | ヘッダー + 接続ドット（緑） + メッセージ一覧 + 入力バー |
| **Loading (初回)** | ヘッダー + スケルトンメッセージ（3つ） + 入力バー無効 |
| **Loading (ストリーミング中)** | AIメッセージにタイピングインジケーター表示、deltaテキストリアルタイム追加 |
| **Empty (新規チャット)** | ヘッダー + 中央にイラスト + 「最初のメッセージを送ろう」 + 入力バー |
| **Error (送信失敗)** | メッセージバブルに赤色ボーダー + リトライボタン表示 |
| **Offline** | オフラインバナー表示、入力バー無効化、接続ドット赤 |
| **Free上限到達** | Freeバナー表示（「本日の無料チャットを使い切りました」）、送信ボタン無効化、ペイウォールボタン |
| **WebSocket接続中 (Pro)** | 接続ドット黄色、ヘッダーに「再接続中...」テキスト |
| **WebSocket切断後フォールバック** | 接続ドット赤、ヘッダーに「Edge Function経由」テキスト、バックグラウンド再接続試行中 |
| **振り返りプロンプト表示 (Pro)** | AIメッセージに📝バッジ、薄いアクセント背景、「今日はどうだった？」 |
| **振り返り回答中 (Pro)** | 文字数制限3,000文字、入力中のカウンター「245/3000」 |
| **AI振り返り生成中 (Pro)** | AIメッセージにローディングインジケーター「振り返りを生成中...」 |
| **メディアアップロード中** | メディアプレビュー + プログレスバー表示、送信ボタン無効化 |
| **メディアアップロード失敗** | エラートースト + リトライボタン表示 |
| **コンテキストメニュー表示** | メッセージ長押しでオーバーレイメニュー（コピー/返信/翻訳） |
| **翻訳中** | 翻訳対象メッセージ下にスピナー表示 |
| **翻訳完了** | メッセージ下に折りたたみ翻訳セクション表示 |
| **OGP取得中** | URLメッセージ下にスケルトンカード表示 |
| **OGP表示** | メッセージ下にOGPカード（タイトル/説明/サムネイル）表示 |
| **スクロール上方向 (FAB表示)** | 最新メッセージから500px以上スクロール → 右下に↓FAB表示（未読バッジ付き） |
| **全画面画像プレビュー** | 画像タップで全画面モーダル表示（ピンチズーム対応、閉じるボタン） |

### インタラクション

| アクション | 動作 | アニメーション |
|-----------|------|------------|
| メッセージ入力 | TextInputに入力、文字数カウンター更新 | — |

### Free / Pro 差分

| 機能 | Free | Pro |
|------|------|-----|
| チャット回数 | 1日3回まで | 無制限 |
| 通信方式 | Supabase Edge Function (SSE) | WebSocket (OpenClaw Gateway) |
| 接続状態表示 | なし | 接続ドット表示（緑/黄/赤） |
| 残り回数バッジ | 表示（2/3） | 非表示 |
| 上限到達時 | Freeバナー + ペイウォールボタン表示 | なし |
| 振り返り機能 | なし | あり（📝バッジ + 日記統合） |
| AI振り返りコメント | なし | あり（80〜150文字） |
| 文字数制限 | 1,000文字（通常チャット） | 1,000文字（通常）/ 3,000文字（振り返り回答） |
| 過去の振り返り閲覧 | 読み取り専用（Proで作成したもの） | 全て閲覧・作成可能 |
| メディア送信 | 画像/動画/音声 | 画像/動画/音声 |
| マークダウン表示 | あり | あり |
| マークダウン入力 | あり | あり |
| コンテキストメニュー | コピー/返信/翻訳 | コピー/返信/翻訳 |
| OGPプレビュー | あり | あり |

## デザインノート

### ビジュアル方針
- **チャット = 日記の統合ビュー** — 独立した日記タブを廃止、チャット内で自然に振り返りを促す
- **視覚的区別** — 振り返りメッセージに📝バッジ + 薄いアクセント背景で通常チャットと区別
- **ストリーミング体験** — リアルタイムdelta表示でAIの思考過程を可視化、エンゲージメント向上
- **プログレッシブ・ディスクロージャ** — 上限到達時のみFreeバナー表示、通常時は邪魔しない
- **低い認知負荷** — シンプルな入力バー、送信ボタンのみで迷わせない
- **アンカリング** — Free上限到達バナーで「Proにアップグレード」を強調、課金導線
- **リッチメッセージ** — マークダウン、メディア添付、OGPプレビューでSlack風のリッチチャット体験
- **コンテキストメニュー** — 長押しでコピー/返信/翻訳、直感的な操作
- **メディア統合** — 入力バー左の「+」ボタンでSlack風メディア添付、視覚的に軽量
- **コード共有** — コードブロックの「コピー」ボタンで開発者UX向上

### 日記統合の視覚表現
- **📝バッジ**: 左上に配置、直径20pt、白背景、薄い影
- **アクセント背景色**: #E8F4F8（薄い青）、通常メッセージ（白/紫）と区別
- **振り返りプロンプト例**: 「今日はどうだった？良かったこと、気になったこと、何でも教えて。」
- **AI振り返りコメント例**: 「今日は成果が出て良かったね。達成感を感じられたのは、あなたの努力の証だよ。」

### マークダウンレンダリング
- **AIメッセージ**: マークダウンとしてレンダリング（見出しh1〜h3、ol/ul リスト、コードブロック、インラインコード、太字、イタリック、リンク）
- **ユーザーメッセージ**: 送信後にマークダウンレンダリング（入力中はプレーンテキスト）
- **コードブロック**: ダーク背景（#1E1E1E）、等幅フォント、右上に「コピー」ボタン
- **リンク**: Primary色（#6C63FF）でアンダーライン、タップで外部ブラウザ
- **XSS対策**: `<script>`, `<iframe>`, `javascript:` 等をサニタイズ

### メディア添付の表示
- **画像**: サムネイル（最大幅70%、最大高さ200pt、アスペクト比維持、角丸8pt）
- **動画**: サムネイル + 中央に半透明再生ボタン（直径48pt）
- **音声**: 波形グラフ（高さ40pt） + 再生/停止ボタン + 再生時間テキスト
- **アップロードプログレス**: バブル内にプログレスバー（Primary色、高さ3pt）

### OGPプレビューカード
- **配置**: メッセージバブルの下、4pt間隔
- **サイズ**: 幅=バブル幅、高さ=auto（最小80pt）
- **構成**: 左にサムネイル（60pt×60pt、角丸4pt） + 右にタイトル（14pt SemiBold、1行）+ 説明文（12pt Regular、2行まで）
- **スタイル**: Surface背景、1pt border #E0E0E0、角丸8pt
- **タップ**: 外部ブラウザでURL表示

### 翻訳表示
- **配置**: メッセージバブルの下、4pt間隔
- **スタイル**: 薄いグレー背景（#F3F4F6）、角丸8pt、パディング8pt
- **ヘッダー**: 「翻訳済み (ja→en)」ラベル、Caption 12pt、タップで開閉
- **本文**: 翻訳テキスト、Body 14pt
- **初回**: 展開状態で表示、以降は折りたたみ

### 最新メッセージに戻るFAB
- **配置**: 画面右下、マージン16pt
- **サイズ**: 48pt × 48pt、角丸24pt
- **スタイル**: 白背景、shadow（offset: 0,2、radius: 4、color: rgba(0,0,0,0.2)）
- **アイコン**: ↓矢印、Primary色（#6C63FF）
- **未読バッジ**: 右上に赤色バッジ（直径20pt）、白テキスト、未読数表示
- **表示条件**: 最新メッセージから500px以上スクロール
- **非表示条件**: 最新メッセージ付近（500px以内）

### 未読/既読管理
- **タブバーバッジ**: チャットタブアイコンの右上に赤色バッジ、未読数表示
- **自動既読**: チャット画面表示時に表示範囲内のメッセージを既読に更新
- **対象**: `role = 'assistant'` かつ `is_read = false` のメッセージのみカウント

### コンテキストメニュー
- **起動**: メッセージバブル長押し（500ms） + haptic feedback
- **スタイル**: オーバーレイ、backdrop blur、メニュー項目は白背景 + 1pt border
- **項目**: コピー（クリップボードアイコン）、返信（返信アイコン、将来実装）、翻訳（翻訳アイコン）
- **テキスト選択**: メッセージ内テキストを長押しで部分選択 → コピー可能

### メッセージバブルの角丸ルール
- **ユーザーメッセージ**: 右上を小さく（4pt）、他を大きく（16pt） → 吹き出し感
- **AIメッセージ**: 左上を小さく（4pt）、他を大きく（16pt） → 吹き出し感
- **連続メッセージ**: 同一送信者の連続メッセージは間隔を4ptに縮小、視覚的にグループ化

### ストリーミング表示の実装
- **SSE（Free）**: `text_delta` イベントを受信 → バブル内テキストに追加
- **WebSocket（Pro）**: `agent.text_delta` イベントを受信 → バブル内テキストに追加
- **タイピングインジケーター**: 点滅カーソル（500ms間隔）
- **完了処理**: `text_done` イベント受信 → タイピングインジケーター消失 → タイムスタンプ表示

### WebSocket接続状態の可視化
- **接続中（緑ドット）**: 通常動作、ヘッダーに「ツイン名」のみ表示
- **再接続中（黄ドット）**: ヘッダーに「再接続中...」テキスト追加、exponential backoff実行中
- **切断（赤ドット）**: 10回再接続失敗後、フォールバックモード、ヘッダーに「Edge Function経由」テキスト
- **フォールバック復帰**: バックグラウンドで5分間隔のWebSocket再接続試行、成功時にトースト表示

### ページネーション
- **初回ロード**: 直近50件
- **追加ロード**: 上方向スクロールで50件ずつ追加
- **最古メッセージ**: 「これ以上メッセージはありません」テキスト表示
- **パフォーマンス**: FlatList の `onEndReached` を使用（inverted: true のため上方向）

### 振り返り機能のタイミング
- **トリガー**: 最後のチャットから6時間以上経過（1日1回まで）
- **プロンプト例**: 「今日はどうだった？」「今日の気持ちを聞かせて」「振り返ってみよう」
- **ユーザー回答**: 通常チャットと同様に入力、文字数制限3,000文字
- **AI振り返り生成**: `journal-reflect` Edge Function 呼び出し、3〜5秒以内に生成
- **保存**: `chat_messages` + `journal_entries` の両方に保存（二重書き込み）

### 文字数制限の動的切り替え
- **通常チャット**: 1,000文字
- **振り返り回答**: 3,000文字（`metadata.isJournalEntry: true` のメッセージ）
- **カウンター表示**: 入力中のモードに応じて制限値を動的に変更（「245/1000」→「245/3000」）
- **上限近づく**: 残り50文字でカウンター色を赤に変更、警告

### Free上限到達時のUX
1. 3回目のメッセージ送信後、レスポンスに `remaining: 0` 含まれる
2. Freeバナー表示: 「本日の無料チャットを使い切りました」
3. 送信ボタン無効化（グレーアウト）
4. バナー内に「Proにアップグレード」ボタン配置
5. ボタンタップでペイウォール画面に遷移
6. 翌日（UTC 0:00）に自動リセット、送信ボタン有効化

### パフォーマンス考慮
- **メッセージリスト**: FlatList仮想化、100件超はスクロール外を破棄
- **ストリーミングdelta**: 16ms（60fps）ごとにバッチ処理、パフォーマンス最適化
- **WebSocket再接続**: exponential backoff（1s → 2s → 4s → 8s → 最大30s）
- **メッセージ保存**: 送受信完了後1秒以内にSupabaseへ保存（非同期）
- **オフライン対応**: 未送信メッセージをローカルキューに保持、復帰時に自動送信
- **アニメーション**: transform使用（opacity + translateY）、layout animationは最小限
