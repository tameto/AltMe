# ナビゲーション構造 仕様書

## 基本情報
- 担当Agent: Agent A (Foundation)
- ルーティングライブラリ: Expo Router v3
- 関連ファイル: app/_layout.tsx, app/(tabs)/_layout.tsx, app/(auth)/_layout.tsx, app/(onboarding)/_layout.tsx, app/(paywall)/_layout.tsx

## 目的
アプリ全体のナビゲーション構造とルーティングガードを定義する。
認証状態・オンボーディング完了状態に基づいて、ユーザーを適切な画面にルーティングする。

## 2. ルーティングガード（_layout.tsx）

### 2.1 ガードロジック

Root Layout（app/_layout.tsx）で以下の条件分岐を実装する。

```
認証チェック（app/_layout.tsx）
├── 未認証かつゲストでない → (auth)/login へ
├── 未認証かつゲストモード → (tabs) へ
│   ├── コミュニティ: 閲覧可（いいね/コメント非表示）
│   ├── チャット: GuestPromptOverlay 表示
│   ├── ツイン: GuestPromptOverlay 表示
│   └── 設定: ゲスト専用マイページ（ログインボタン + グレーアウト設定一覧）
├── 認証済みかつオンボーディング未完了 → (onboarding)/welcome へ
└── 認証済みかつオンボーディング完了 → (tabs) へ
    └── Pro機能 → subscriber チェック
```

**ゲストモード実装詳細:**
- `auth-store` に `isGuest: boolean` と `enterGuestMode()` 追加
- タブ各画面内で `isAuthenticated` 判定して条件分岐表示
- `GuestPromptOverlay` は専用コンポーネント（画面ではなくオーバーレイ）

### 2.2 アクセスレベル

| レベル | 対象ユーザー | アクセス可能画面 |
|--------|------------|---------------|
| guest | 未認証 | コミュニティ一覧・詳細（閲覧のみ） |
| authenticated | 認証済み（Free含む） | 全タブ（Pro機能は制限付き） |
| subscriber | Pro課金済み | 全機能アクセス可能 |

### 2.3 判定に使用するデータ

| 条件 | データソース | 判定方法 |
|------|------------|---------|
| 認証状態 | Supabase Auth (useAuthStore) | session が null でないこと |
| オンボーディング完了 | profiles.onboarding_completed | true/false |
| サブスク状態 | useSubscriptionStore | EntitlementInfo.isPro |

### 2.3 ガード実装の注意事項

- 認証状態の確認中はスプラッシュ画面（またはローディング）を表示し、画面のちらつきを防止する
- Supabase Auth の onAuthStateChange リスナーで認証状態の変化を監視する
- オンボーディング完了状態は profiles テーブルから取得し、Zustand Store にキャッシュする
- ディープリンクからのアクセス時もガードが正しく動作すること

## 4. タブ間遷移

### 4.1 タブ切替時の動作
| 遷移元 → 遷移先 | 動作 |
|----------------|------|
| 任意タブ → チャット | チャット履歴をリフレッシュ（最新メッセージ表示） |
| 任意タブ → コミュニティ | Pro判定。Free → ブラー表示 + ペイウォール誘導、Pro → AIツイン会話リスト表示 |
| 任意タブ → ツイン情報 | 性格データ + 気分トラッキング + OpenClawステータスを最新化 |
| 任意タブ → 設定 | プロフィール・サブスク・インスタンス情報を最新化 |

### 4.2 モーダル表示のトリガー
| モーダル | トリガー | 遷移元 |
|---------|---------|--------|
| ペイウォール | Free機能制限タップ、設定画面「Proにアップグレード」タップ | コミュニティタブ、設定タブ |
| サブスク管理 | 設定画面「サブスクリプション管理」タップ | 設定タブ |
| ツイン会話詳細 | コミュニティタブの会話アイテムタップ | コミュニティタブ |
| アカウント削除確認 | 設定画面「アカウント削除」タップ | 設定タブ |

## 5. ディープリンク対応

### 5.1 対応するディープリンク
| リンク | 遷移先 | 備考 |
|--------|--------|------|
| altme://chat | (tabs)/index.tsx | プッシュ通知からのチャット起動 |
| altme://community | (tabs)/community.tsx | コミュニティ通知からの起動（Pro限定） |
| altme://twin | (tabs)/twin.tsx | ツイン情報通知からの起動 |
| altme://paywall | (paywall)/index.tsx | プロモーション通知からの起動 |

### 5.2 ディープリンク時のガード動作
- 未認証状態でディープリンクを受信 → ログイン後に目的画面にリダイレクト
- オンボーディング未完了状態でディープリンクを受信 → オンボーディング完了後に目的画面にリダイレクト
