# セキュリティチェックリスト（全項目）

## クライアントサイド

### 認証情報管理
- [ ] API キーがソースコードにハードコードされていない
- [ ] .env が .gitignore に含まれている
- [ ] .env.example にはプレースホルダーのみ（実値なし）
- [ ] service_role key がクライアントコードに含まれていない
- [ ] SecureStore/Keychain でトークンを保存

### 入力バリデーション
- [ ] ユーザー入力のサニタイズ
- [ ] 最大文字数制限
- [ ] 型チェック（数値フィールドに文字列が入らない等）

### データ保護
- [ ] AsyncStorage に機密データを保存していない
- [ ] ログに個人情報を出力していない
- [ ] デバッグ機能が本番で無効（__DEV__）
- [ ] ソースマップが本番ビルドに含まれていない

## サーバーサイド（Supabase）

### RLS
- [ ] 全 public テーブルで RLS 有効
- [ ] SELECT: auth.uid() = user_id
- [ ] INSERT: auth.uid() = user_id
- [ ] UPDATE: auth.uid() = user_id
- [ ] DELETE: ポリシー設定済み（or ソフトデリート）

### Edge Functions
- [ ] 全 Function で認証チェック
- [ ] 入力バリデーション
- [ ] レスポンスに内部情報を含まない
- [ ] CORS 設定が適切
- [ ] タイムアウト設定

### Auth
- [ ] メール確認有効（本番）
- [ ] パスワードポリシー設定
- [ ] セッション有効期限設定

## インフラ（DigitalOcean）

### ネットワーク
- [ ] ファイアウォール設定
- [ ] 不要ポート閉鎖
- [ ] HTTPS/WSS のみ

### サーバー
- [ ] SSH キー認証のみ
- [ ] 自動セキュリティアップデート
- [ ] Docker コンテナが非 root
- [ ] cloud-init にシークレットなし

## 依存関係
- [ ] npm audit クリーン
- [ ] package-lock.json コミット済み
- [ ] 既知の脆弱性なし
