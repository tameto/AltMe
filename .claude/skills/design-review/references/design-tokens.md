## タイポグラフィ

### fontFamily

**許可値**: `"Outfit"` のみ（全画面統一）

アイコンフォント: `"lucide"` のみ

### fontSize 許可スケール

| カテゴリ | サイズ | 用途 |
|---------|--------|------|
| Display | 28, 30, 32 | 画面タイトル（大） |
| Heading 1 | 24 | セクションタイトル |
| Heading 2 | 20 | サブセクション、カードタイトル |
| Heading 3 | 18 | リスト見出し |
| Body Large | 16 | 本文（大） |
| Body | 14 | 本文（標準）、ボタンテキスト |
| Caption | 13 | キャプション、補足テキスト |
| Small | 12 | タブラベル、バッジ |
| Tiny | 11 | タイムスタンプ、フッター注記 |

**非許可**: 10px 以下（iOS HIG 最小 11pt）、15px（13 or 16 を使う）、17px（16 or 18 を使う）、19px（18 or 20 を使う）

### fontWeight 許可値

| 値 | 名前 | 用途 |
|----|------|------|
| `"400"` | Regular | 本文、説明文 |
| `"500"` | Medium | 強調本文、ナビゲーションラベル |
| `"600"` | SemiBold | カードタイトル、ボタン、ユーザー名 |
| `"700"` | Bold | 画面タイトル、重要な見出し |

**非許可**: `"300"` (Light)、`"800"` (ExtraBold)、`"900"` (Black)

## 間隔

### padding 許可値

`4, 8, 10, 12, 14, 16, 20, 24, 32, 40`

**よく使うパターン**:
- 画面全体: `[0, 20, 0, 20]` (左右20)  or `[20, 20, 20, 20]` (全方向20)
- カード: `[16, 16, 16, 16]` or `[20, 20, 20, 20]`
- ボタン: `[14, 24, 14, 24]` (上下14, 左右24)
- リスト項目: `[12, 16, 12, 16]`
- タブバー: `[8, 0, 8, 0]`
- ヘッダー: `[12, 20, 12, 20]`

### gap 許可値

`2, 4, 6, 8, 10, 12, 16, 20, 24, 30, 32, 40`

**よく使うパターン**:
- テキスト間（タイト）: 2, 4
- アイコン+テキスト: 6, 8
- フォーム項目間: 12, 16
- セクション間: 20, 24
- カード間: 16, 20
- 画面行内の画面間: 30
- マスターボードのセクション間: 40

### cornerRadius 許可値

`0, 4, 8, 12, 16, 20, 28`

**よく使うパターン**:
- ボタン: `[12, 12, 12, 12]` or `[28, 28, 28, 28]` (pill)
- カード: `[16, 16, 16, 16]` or `[20, 20, 20, 20]`
- 入力フィールド: `[12, 12, 12, 12]`
- アバター: `[20, 20, 20, 20]` (円形)
- チャットバブル（ユーザー）: `[16, 16, 4, 16]`
- チャットバブル（AI）: `[4, 16, 16, 16]`（Slack風なら不要）
- タブバー: `[0, 0, 0, 0]`
- モーダル: `[20, 20, 0, 0]` (上だけ角丸) or `[20, 20, 20, 20]`

## 横断チェックの実行方法

### search_all_unique_properties の呼び出し例

```json
{
  "filePath": "{file}",
  "parents": ["{全画面IDをカンマ区切り}"],
  "properties": [
    "fillColor", "textColor", "strokeColor",
    "fontSize", "fontFamily", "fontWeight",
    "cornerRadius", "padding", "gap"
  ]
}
```

### 結果の分析

1. 各プロパティの全ユニーク値を抽出
2. 上記の許可リストと照合
3. 許可リスト外の値を Warning として記録
4. 値のバリエーション数が多すぎる場合も Warning（例: fontSize が20種類以上）

### replace_all_matching_properties での一括修正

```json
{
  "filePath": "{file}",
  "parents": ["{全画面IDをカンマ区切り}"],
  "properties": {
    "fontFamily": [{"from": "Inter", "to": "Outfit"}],
    "textColor": [{"from": "#6B7280", "to": "#64748B"}]
  }
}
```
