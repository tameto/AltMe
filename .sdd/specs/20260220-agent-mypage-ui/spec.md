## User Scenarios & Testing *(mandatory)*

### User Story 1 - マイエージェント画面でAIツインのプロフィールを確認する (Priority: P1)

認証済みユーザーがマイエージェントタブを開き、自分のAIツインの全体像（アバター画像、名前、MBTIタイプ、オンライン状態、性格特性）を一目で確認できる。

**Why this priority**: AIツインの「存在感」を最も直接的に伝える画面。ユーザーのエンゲージメントと継続利用の核となる。

**Independent Test**: マイエージェントタブを開いて、アバター・名前・MBTIバッジ・オンライン状態・パーソナリティ特性が全て正しく表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** オンボーディング完了済みの認証ユーザー, **When** マイエージェントタブを開く, **Then** AIツインのアバター画像が丸枠で表示され、右下にオンライン状態インジケータ（緑ドット）が見える
2. **Given** 同上, **When** 画面がロードされる, **Then** ツイン名（profiles.twin_name）が大きく表示される
3. **Given** MBTIタイプが設定済み, **When** 画面がロードされる, **Then** ツイン名の下にMBTIバッジ（例: "INFP"）が表示される
4. **Given** MBTIタイプが未設定, **When** 画面がロードされる, **Then** MBTIバッジは非表示になる
5. **Given** 性格診断完了済み, **When** 画面がロードされる, **Then** Big Five 5トレイト（外向性、協調性、誠実性、神経症傾向、開放性）がプログレスバーとパーセンテージで表示される
6. **Given** Proユーザーかつインスタンスが稼働中, **When** 画面がロードされる, **Then** オンラインインジケータが緑色で表示される
7. **Given** Freeユーザーまたはインスタンス非稼働, **When** 画面がロードされる, **Then** オンラインインジケータがグレーで表示される

---

### User Story 2 - マイページ画面で設定メニューを操作する (Priority: P1)

認証済みユーザーがマイページタブを開き、プロフィール情報の確認と各種設定へのアクセスができる。設定項目はスクリーンショットの順序で表示される。

**Why this priority**: 設定画面はユーザーの全体的な操作導線のハブ。Pro変換（アップグレード）とアカウント管理に直結する。

**Independent Test**: マイページタブを開いて、ユーザー情報・アップグレードボタン・全設定項目が正しい順序で表示され、各タップで適切な遷移/動作が行われることを確認する。

**Acceptance Scenarios**:

1. **Given** 認証済みユーザー, **When** マイページタブを開く, **Then** ユーザー表示名とメールアドレスがプロフィールカードに表示される
2. **Given** Freeユーザー, **When** マイページタブを開く, **Then** プロフィールカードの下にゴールドの「Proにアップグレード」ボタンが表示される
3. **Given** Proユーザー, **When** マイページタブを開く, **Then** プロフィールカードにProバッジが表示され、アップグレードボタンは非表示
4. **Given** 認証済みユーザー, **When** 設定リストを表示する, **Then** 以下の順序で設定項目が表示される:
   - サブスクリプション管理
   - 通知設定
   - プライバシー
   - AIツインの設定（サブタイトル付き）
   - 性格診断やり直し
   - 言語
   - ヘルプ
   - 利用規約・プライバシーポリシー（統合アイテム）
5. **Given** 認証済みユーザー, **When** 設定リストの最後を見る, **Then** 赤い「アカウントを削除」テキストとログアウトボタンが表示される
6. **Given** MBTI設定済み + OpenClawインスタンス稼働中, **When** 「AIツインの設定」項目を見る, **Then** サブタイトルに「MBTI: INFP」「OpenClaw: 接続中」が表示される

### User Story 3 - FreeユーザーがProへのアップグレードを促される (Priority: P2)

Freeユーザーがマイページのアップグレードボタンをタップし、ペイウォール画面に遷移して課金フローに入る。

**Why this priority**: マネタイズの重要な導線。マイページ経由のPro変換率向上に直結する。

**Independent Test**: Freeユーザーとしてマイページを開き、「Proにアップグレード」ボタンをタップしてペイウォール画面に遷移することを確認する。

**Acceptance Scenarios**:

1. **Given** Freeユーザーがマイページを表示, **When** 「Proにアップグレード」ボタンをタップ, **Then** ペイウォール画面に遷移する
2. **Given** トライアル中のユーザー, **When** マイページを表示する, **Then** アップグレードボタンは非表示（Proバッジ表示）

---

### User Story 4 - AIツインの設定情報をマイページから確認する (Priority: P2)

認証済みユーザーがマイページの「AIツインの設定」項目から、現在のMBTI設定とOpenClawインスタンスの接続状態を一目で確認できる。

**Why this priority**: ユーザーがAIツインの設定状態を常に把握できることで安心感を提供する。

**Independent Test**: 「AIツインの設定」のサブタイトルにMBTIタイプとOpenClaw接続状態が正しく反映されることを確認する。

**Acceptance Scenarios**:

1. **Given** MBTI未設定かつインスタンス未作成, **When** マイページを表示, **Then** サブタイトルは「MBTI: 未設定」のみ表示
2. **Given** MBTI: ENFJ かつインスタンス稼働中, **When** マイページを表示, **Then** サブタイトルに「MBTI: ENFJ, OpenClaw: 接続中」
3. **Given** インスタンスがエラー状態, **When** マイページを表示, **Then** サブタイトルに「OpenClaw: エラー」（赤テキスト）
4. **Given** Freeユーザー, **When** マイページを表示, **Then** OpenClaw接続状態は非表示（MBTIのみ）

---

### User Story 5 - SOUL.mdをマイエージェント画面から閲覧する (Priority: P3)

Proユーザーがマイエージェント画面のSOUL.md閲覧ボタンをタップし、AIツインの性格設定ドキュメントをモーダルで確認できる。

**Why this priority**: Pro限定機能としてAIツインのカスタマイズ透明性を提供。解約防止に貢献。

**Independent Test**: SOUL.md閲覧ボタンをタップしてモーダルが開き、内容が正しく表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** Proユーザーかつインスタンス稼働中, **When** SOUL.md閲覧ボタンをタップ, **Then** SOUL.md内容がモーダルで表示される
2. **Given** Freeユーザー, **When** マイエージェント画面を表示, **Then** SOUL.md閲覧ボタンは非表示またはロック状態
3. **Given** SOUL.md未生成, **When** 閲覧ボタンをタップ, **Then** 「まだ生成されていません」メッセージが表示される

---

### User Story 6 - 未認証ユーザーにゲスト表示を提供する (Priority: P3)

未認証（ゲスト）ユーザーがマイエージェント・マイページタブにアクセスした場合、適切な誘導表示を行う。

**Why this priority**: ゲストブラウズモードの一貫したUX。ログイン変換への導線。

**Independent Test**: 未認証状態で各タブにアクセスし、ゲスト用の表示が正しく出ることを確認する。

**Acceptance Scenarios**:

1. **Given** 未認証ユーザー, **When** マイエージェントタブを開く, **Then** GuestPromptOverlay（ログイン誘導）が表示される
2. **Given** 未認証ユーザー, **When** マイページタブを開く, **Then** ゲスト専用マイページ（ログインボタン + 機能紹介）が表示される

---

### Edge Cases

- **ネットワーク切断中**: 性格診断データやOpenClawステータスの取得失敗時、最後のキャッシュデータで表示 + エラー注記
- **アプリバックグラウンド復帰**: タブに戻った際にデータを再取得（stale while revalidate パターン）
- **性格診断未実施**: パーソナリティ特性セクションに「診断を受けてください」誘導を表示
- **プログレスバーの境界値**: スコア 0% と 100% で正しく描画される
- **表示名・ツイン名が未設定**: デフォルト値で表示（表示名: "ゲスト"、ツイン名: "AltMe"）
- **OpenClawインスタンスの各ステータス**: cold/waking/healthy/sleeping/error 各状態がオンラインインジケータに正しく反映
- **MBTI未設定時のバッジ非表示**: マイエージェント画面でMBTIバッジ領域が消え、レイアウトが崩れない
- **設定項目タップ時のローディング**: 遷移先画面のロード中にフィードバック表示

## Requirements *(mandatory)*

### Functional Requirements

**マイエージェント画面（twin.tsx）**
- **FR-001**: マイエージェント画面にAIツインのアバター画像を表示する。アバター画像はユーザーが選択したアバターアイコンタイプ（geometric/cosmic/organic/tech/zen）に応じたものとする
- **FR-002**: ツイン名をアバターの下に目立つサイズで表示する
- **FR-003**: MBTI設定済みの場合、ツイン名の下にMBTIタイプのバッジを表示する。未設定時はバッジを非表示にする
- **FR-004**: オンライン状態インジケータをアバター右下に表示する。Proユーザーかつインスタンスが healthy/waking の場合は緑、それ以外はグレーとする
- **FR-005**: Big Five 5トレイトをプログレスバーとパーセンテージで表示する。トレイト名はi18n対応とする
- **FR-006**: SOUL.md閲覧ボタンを画面下部に配置し、タップでモーダル表示する。Freeユーザーには閲覧制限を設ける
- **FR-007**: 未認証ユーザーにはGuestPromptOverlayを表示する

**マイページ画面（settings.tsx）**
- **FR-008**: プロフィールカードにユーザー表示名、メールアドレス、Proバッジ（Proのみ）を表示する
- **FR-009**: Freeユーザーにはプロフィールカード直下にゴールドの「Proにアップグレード」ボタンを表示する。タップでペイウォール画面に遷移する
- **FR-010**: 設定メニュー項目を以下の順序で表示する: サブスクリプション管理、通知設定、プライバシー、AIツインの設定、性格診断やり直し、言語、ヘルプ、利用規約・プライバシーポリシー
- **FR-011**: 「AIツインの設定」項目にサブタイトルを表示する。MBTI設定済みなら「MBTI: {type}」、Proかつインスタンス稼働中なら「OpenClaw: 接続中」を含む
- **FR-012**: 「性格診断やり直し」項目タップでオンボーディングの性格診断画面に遷移する（確認ダイアログ付き）
- **FR-013**: 「利用規約・プライバシーポリシー」を1つの設定アイテムとして統合し、タップで外部ブラウザを開く
- **FR-014**: 設定リストの末尾に赤い「アカウントを削除」テキストリンクを配置する
- **FR-015**: ログアウトボタンを「アカウントを削除」の上に配置する
- **FR-016**: 画面最下部にアプリバージョンを表示する
- **FR-017**: 未認証ユーザーにはゲスト専用マイページ（ログインボタン + グレーアウト設定一覧）を表示する

**共通**
- **FR-018**: 両画面の全テキストをi18n（日本語/英語）対応する
- **FR-019**: 両画面でCosmicBackground + Dark Premium UIスタイルを統一する

### Key Entities

- **UserProfile**: ユーザーの基本情報（表示名、メール、ツイン名、MBTIタイプ、アバターアイコン）
- **PersonalityTraits**: Big Five 5トレイトのスコア（0-100）
- **OpenClawInstance**: AIツインのインスタンス情報（ステータス、ランタイム状態）
- **EntitlementInfo**: 課金状態（Free/Pro/Trial）

## Assumptions

- アバター画像はデザインシステムに定義された5種類（geometric/cosmic/organic/tech/zen）のアイコンを使用する。ユーザーアップロード画像は将来の拡張として扱う
- OpenClawインスタンスのステータス取得は既存の `getMyInstance()` と `subscribeToInstanceChanges()` を使用する
- 「サブスクリプション管理」タップはOS標準のサブスクリプション管理またはアプリ内管理画面に遷移する
- 「言語」設定はタップ時にアラートで表示（coming soon）。本格実装は別タスク
- 「プライバシー」と「利用規約・プライバシーポリシー」は別項目として残す（プライバシーはアプリ内設定、利用規約・PPは外部リンク）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: マイエージェント画面がロード完了するまで2秒以内（ネットワーク正常時）
- **SC-002**: 全設定項目が正しい順序で表示され、タップで適切な画面に遷移する（遷移成功率100%）
- **SC-003**: Freeユーザーの90%以上がアップグレードボタンを視認できる位置に配置されている（ファーストビュー内）
- **SC-004**: オンラインインジケータがOpenClawステータスと一致する（ステータス反映遅延5秒以内）
- **SC-005**: Big Fiveパーソナリティ特性がスコア0-100の全範囲で正しく表示される
- **SC-006**: 全テキストが日本語・英語の両方で正しく表示される
- **SC-007**: ゲストユーザーに適切な誘導表示がされ、認証導線にアクセスできる
