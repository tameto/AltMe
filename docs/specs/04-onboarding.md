## 1. 概要

オンボーディングはAltMeの最重要フロー。
**目的**: ユーザーに8分以内にAI分身の価値を体感させ、ペイウォールへ自然に導く。

### 1.1 フロー全体図

```
(onboarding)/welcome.tsx
       │
       ▼
(onboarding)/personality-quiz.tsx（5問）
       │
       ▼
(onboarding)/result.tsx（性格診断結果）
       │
       ▼
(onboarding)/meet-twin.tsx（AI分身お披露目 + 初回チャット3往復）
       │
       ▼
(paywall)/index.tsx（フルスクリーンペイウォール）
       │
       ├── 購入/トライアル → (tabs)/index.tsx
       └── スキップ → (tabs)/index.tsx（Free制限付き）
```

### 2.2 性格診断 — `(onboarding)/personality-quiz.tsx`

#### 質問設計（5問）

各質問はBig Five性格特性に対応。タップ式の選択肢で素早く回答可能にする。

| # | 質問テキスト | 対応特性 | 選択肢 |
|---|------------|---------|--------|
| 1 | 「週末の理想的な過ごし方は？」 | Extraversion | A: 友達とワイワイ / B: 少人数でゆっくり / C: 一人でリラックス / D: 新しい場所を探索 |
| 2 | 「仕事で問題が起きたらまず何をする？」 | Conscientiousness | A: 計画を立てて段階的に / B: まず全体像を把握 / C: 直感で動く / D: 誰かに相談する |
| 3 | 「SNSで話題の新しいことが出てきたら？」 | Openness | A: すぐ試してみる / B: 調べてから判断 / C: あまり興味ない / D: 誰かの感想を待つ |
| 4 | 「友人が落ち込んでいたら？」 | Agreeableness | A: すぐ話を聞きに行く / B: そっとメッセージを送る / C: 時間を置いてから声をかける / D: 具体的な解決策を提案する |
| 5 | 「大事なプレゼンの前日は？」 | Neuroticism | A: 準備を完璧にして安心する / B: やることやったら気にしない / C: 少し不安だけど大丈夫 / D: 緊張して眠れないかも |

| アクション | 動作 |

| 最後の質問回答 | result.tsx に遷移 + AI分析APIリクエスト開始 |

#### チャット動作仕様

| ステップ | 発言者 | 内容 |
|---------|-------|------|
| 1 | AI分身 | 自己紹介（性格診断結果に基づくパーソナライズ） |
| 2 | ユーザー | 自由入力（テキスト） |
| 3 | AI分身 | 応答（パーソナライズ） |
| 4 | ユーザー | 自由入力 |
| 5 | AI分身 | 洞察プレビュー（一部ブラー表示）+ 「もっと話したい」 |
| 6 | ユーザー | 自由入力 |
| 7 | AI分身 | 最終メッセージ + 「続きは解除してね」 |

3往復後、「続きを解除する」→ ペイウォール表示

| アクション | 動作 |
|-----------|------|
| 「続きを解除する」タップ | (paywall)/index.tsx に遷移 |
| 「もう少し後で」タップ | onboardingCompleted = true → (tabs)/ に遷移（Free） |

## 3. AI分身の名前設定

### 3.1 デフォルト名
AI分身の名前はユーザー名 + "AI" をデフォルトとする。
例: ユーザー名「太郎」→ AI分身名「太郎AI」

### 3.2 カスタム名（Phase 2）
Pro ユーザーは設定画面からAI分身の名前を変更可能。

## 4. 状態管理

### 4.1 オンボーディング進捗の永続化

```typescript
// onboardingCompleted は profiles テーブルに保存
// オンボーディング中の途中経過は useOnboardingStore（メモリ内）
// 性格診断結果は personality_results テーブルに保存
```

### 4.2 再オンボーディング

一度完了したオンボーディングはスキップする。
設定画面から「性格を再診断」でpersonality-quizからやり直し可能（クレジット消費）。
