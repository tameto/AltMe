## 1. 概要

オンボーディングはAltMeの最重要フロー。
**目的**: ユーザーに8分以内にAI分身の価値を体感させ、ペイウォールへ自然に導く。

6画面で構成される:
1. ウェルカム --- アプリ説明
2. 性格診断 --- Big Five 5問
3. 結果表示 --- 棒グラフ + サマリー
4. アイコン選択 --- AIツインの見た目
5. 口調選択 --- AIツインの話し方
6. ツイン初対面 --- 名前設定 + 初回チャット3往復

### 1.1 フロー全体図

```
(onboarding)/welcome.tsx
       |
       v
(onboarding)/personality-quiz.tsx（5問）
       |
       v
(onboarding)/result.tsx（性格診断結果 + 詳細分析ブラー）
       |
       v
(onboarding)/choose-avatar.tsx（AIアイコン選択 5パターン）
       |
       v
(onboarding)/choose-tone.tsx（口調パターン選択 5種類）
       |
       v
(onboarding)/meet-twin.tsx（名前設定 + 初回チャット3往復）
       |
       v
(paywall)/index.tsx（フルスクリーンペイウォール）
       |
       +-- 購入/トライアル --> (tabs)/index.tsx
       +-- スキップ --> (tabs)/index.tsx（Free制限付き）
```

### 1.2 課金導線（Revenue First）

| トリガー | 画面 | 手法 |
|---------|------|------|
| 第1トリガー | result.tsx | 詳細分析をブラー表示。「自分のことをもっと知りたい」欲求 |
| 第2トリガー | meet-twin.tsx | 3往復制限。「もっと話したい」欲求 |
| ペイウォール | paywall/index.tsx | Day 0 課金導線。欲求最高潮でペイウォール表示 |

### 2.2 性格診断 --- `(onboarding)/personality-quiz.tsx`

#### 質問設計（5問 x 4択）

各質問はBig Five性格特性に対応。タップ式の選択肢で素早く回答可能にする。

| # | 質問テキスト | 対応特性 | 選択肢 |
|---|------------|---------|--------|
| 1 | 「新しいことを試すのが好きですか？」 | Openness | とてもそう思う / ややそう思う / あまりそう思わない / 全くそう思わない |
| 2 | 「計画を立ててから行動しますか？」 | Conscientiousness | 同上 |
| 3 | 「大人数の集まりでエネルギーをもらいますか？」 | Extraversion | 同上 |
| 4 | 「他人の気持ちに敏感ですか？」 | Agreeableness | 同上 |
| 5 | 「ストレスを感じやすい方ですか？」 | Neuroticism | 同上 |

**注意**: 実装コード (`onboarding-store.ts`) の質問テキストと仕様書 (`personality-analyze/index.ts`) のシステムプロンプト内の質問テキストは異なる。Edge Function側は汎用的な分析プロンプトで回答値（`strongly_agree` 等）を解釈する。

#### スコアリング

| 回答 | 値 | スコア |
|------|-----|-------|
| とてもそう思う | `strongly_agree` | 100点 |
| ややそう思う | `agree` | 66点 |
| あまりそう思わない | `disagree` | 33点 |
| 全くそう思わない | `strongly_disagree` | 0点 |

#### 画面レイアウト

```
+------------------------------+
| <- 戻る              1/5     |
|                              |
| ================== (20%)     |
|                              |
| 「新しいことを試すのが        |
|   好きですか？」              |
|                              |
| +------------------------+   |
| | とてもそう思う           |   |
| +------------------------+   |
|                              |
| +------------------------+   |
| | ややそう思う             |   |
| +------------------------+   |
|                              |
| +------------------------+   |
| | あまりそう思わない        |   |
| +------------------------+   |
|                              |
| +------------------------+   |
| | 全くそう思わない          |   |
| +------------------------+   |
|                              |
+------------------------------+
```

| アクション | 動作 |
|-----------|------|
| 選択肢タップ | カードハイライト（紫背景）、フェード遷移で次の質問へ |
| 戻るボタン | 前の質問に戻る（1問目では無効化） |
| 5問目回答完了 | `personality-analyze` Edge Function 呼び出し → `result.tsx` へ遷移 |

#### 回答の保存

```typescript
// useOnboardingStore（Zustand）
type OnboardingStore = {
  currentStep: number;          // 0-4
  answers: Answer[];            // { questionId, answer }[]
  personalityResult: PersonalityResult | null;
  isAnalyzing: boolean;

  addAnswer: (questionId: string, answer: string) => void;
  goNext: () => void;
  goPrev: () => void;
  setResult: (result: PersonalityResult) => void;
  setAnalyzing: (analyzing: boolean) => void;
  reset: () => void;
};
```

### 2.3 結果画面 --- `(onboarding)/result.tsx`

5問の回答を `personality-analyze` Edge Function に送信し、性格分析結果を生成・表示する。

```
+------------------------------+
|                              |
|     あなたの性格タイプ         |
|                              |
|   +----------------------+   |
|   | パーソナリティチャート  |   |
|   |                      |   |
|   | 開放性    ====---- 80 |   |
|   | 誠実性    ========= 92 |   |
|   | 外向性    ====------ 45 |   |
|   | 協調性    =======--- 72 |   |
|   | 神経質傾向 ===------- 35 |   |
|   +----------------------+   |
|                              |
|   [性格サマリーテキスト]       |
|   「好奇心旺盛で計画的...」    |
|                              |
|   +----------------------+   |
|   | 詳細分析を見る [Pro限定] |   |
|   | (ブラー + 低透明度)     |   |
|   +----------------------+   |
|                              |
|  +------------------------+  |
|  |  AIツインと会う          |  |
|  +------------------------+  |
|                              |
+------------------------------+
```

#### AI分析APIリクエスト

```
POST /functions/v1/personality-analyze
Authorization: Bearer {supabase_jwt}

Request:
{
  "answers": [
    { "questionId": "q1", "answer": "strongly_agree" },
    { "questionId": "q2", "answer": "agree" },
    ...
  ]
}

Response:
{
  "summary": "好奇心旺盛で...",
  "detailedAnalysis": "あなたのBig Five分析...",
  "personalityTraits": {
    "openness": 85,
    "conscientiousness": 60,
    "extraversion": 70,
    "agreeableness": 75,
    "neuroticism": 40
  },
  "twinPersonality": "あなたの分身は..."
}
```

Edge Function 内部処理:
1. JWT検証 → ユーザーID取得
2. 回答バリデーション
3. OpenAI GPT-4o mini に回答を送信 → Big Five分析 + サマリー生成
4. `personality_results` テーブルに upsert（`user_id` で一意制約）
5. レスポンス返却

**フォールバック**: Edge Function エラー時はローカルでスコア50の均一値を使用。

| アクション | 動作 |
|-----------|------|
| ローディング状態 | 「あなたの性格を分析中...」+ スピナー表示 |
| 「AIツインと会う」タップ | `choose-avatar.tsx` に遷移 |
| 「詳細分析を見る」タップ | 将来実装（MVP段階ではブラー表示のみ） |

#### チャット動作仕様

| ステップ | 発言者 | 内容 |
|---------|-------|------|
| 0 | AI分身 | 自動初回メッセージ（性格診断結果の最高トレイトに基づくパーソナライズ挨拶） |
| 1 | ユーザー | 自由入力 |
| 2 | AI分身 | 応答（`onboarding-chat` Edge Function 経由） |
| 3 | ユーザー | 自由入力 |
| 4 | AI分身 | 応答 |
| 5 | ユーザー | 自由入力 |

3往復（ユーザー3回送信）後、入力フィールド無効化 → 「続きを解除する」ボタン表示。

#### 名前設定

実装上はMVP段階で名前入力UIは省略されている。AI分身はデフォルト名で動作する。
仕様上は以下を定義:
- デフォルト名: 「ツイン」
- 最大文字数: 20文字
- 空文字不可

```typescript
// Big Five最高トレイトに応じた挨拶を選択
const traitGreetings: Record<string, string> = {

  agreeableness: 'はじめまして！...他者への思いやりが深いあなたのように...',

```

| アクション | 動作 |
|-----------|------|
| メッセージ送信 | `onboarding-chat` Edge Function 経由でAI応答取得 |
| 「続きを解除する」タップ | `(paywall)/index.tsx` に遷移 |

| Pro購入後にこの画面に戻った場合 | 自動的に `onboarding_completed = true` → `(tabs)/` にリダイレクト |

## 3. データ仕様

### 3.1 使用テーブル

| テーブル | 用途 | 操作タイミング |

### 3.3 profiles テーブルの追加カラム

| カラム | 型 | デフォルト | 説明 |
|--------|-----|---------|------|
| avatar_icon | TEXT | `'geometric'` | AIアイコンタイプ（geometric/cosmic/organic/tech/zen） |
| speech_tone | TEXT | `'friendly'` | 口調パターン（polite/friendly/intellectual/mentor/tsundere） |

## 4. 状態管理

### 4.1 オンボーディング進捗の永続化

```
- onboarding_completed: profiles テーブルに保存
- 診断中の途中経過: useOnboardingStore（メモリ内、永続化なし）
- 性格診断結果: personality_results テーブルに保存
- アイコン/口調選択: Zustand に一時保存 → 完了時に profiles テーブルに保存
```

### 4.2 途中離脱時の動作

- アプリ強制終了: 次回起動時にウェルカム画面から再開
- Zustand のステートはメモリ内のみ（persist なし）

### 4.3 再オンボーディング

設定画面から「性格を再診断」で `personality-quiz` からやり直し可能。
新しいレコードが `personality_results` に upsert される。

## 5. Edge Functions

### 5.1 personality-analyze

| 項目 | 値 |
|------|-----|
| エンドポイント | `POST /functions/v1/personality-analyze` |
| 認証 | Supabase JWT |
| モデル | GPT-4o mini |
| temperature | 0.7 |
| maxTokens | 2048 |
| タイムアウト | 30秒 |
| フォールバック | ローカルで全トレイト50点の均一値 |

### 5.2 onboarding-chat

| 項目 | 値 |
|------|-----|
| エンドポイント | `POST /functions/v1/onboarding-chat` |
| 認証 | Supabase JWT |
| 入力 | `{ messages, personalityResult, messageCount }` |
| 出力 | `{ message: string }` |
| フォールバック | 固定テンプレートメッセージ |

## 6. エラーハンドリング

| エラーケース | 表示 | リカバリー |
|------------|------|-----------|
| Edge Function タイムアウト (30秒以上) | 「分析に時間がかかっています」+ リトライボタン | 再呼び出し |
| Edge Function 500エラー | 「分析に失敗しました」 | ローカルスコア50均一値にフォールバック |
| ネットワーク未接続 | オフラインバナー | 回答をローカル保存、接続回復後に分析 |
| AI応答エラー (onboarding-chat) | 「返信の取得に失敗しました」+ リトライボタン | テンプレートメッセージにフォールバック |
| DB保存失敗 | ログのみ（UX損なわない） | ローカル一時保存 → 次回起動時リトライ |
| 名前入力に制御文字 | サニタイズして保存 | --- |
| 途中でアプリ強制終了 | --- | 次回起動時にウェルカム画面から再開 |
