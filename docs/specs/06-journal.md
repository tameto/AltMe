## 1. 概要

日記機能はPro専用。ユーザーがテキストで日記を書くと、AI分身が分析・振り返りコメントを生成する。
感情トラッキングと連携し、長期的な自己理解を促進 → リテンション向上 → チャーン低下。

## 3. 機能仕様

### 3.1 日記作成

| 項目 | 仕様 |
|------|------|
| アクセス制限 | Pro専用（Entitlement 'pro' が必要） |
| 気分選択 | 5段階（great/good/neutral/bad/terrible）、必須 |
| 本文 | テキスト入力、1〜3,000文字 |
| タグ | 任意、プリセット（仕事/健康/趣味/人間関係/お金/学び）+ カスタム |
| AI振り返り | 保存後にバックグラウンドで生成（3〜5秒） |
| 1日の上限 | なし（何件でも作成可能） |

### 3.2 AI振り返りコメント生成

保存後、Supabase Edge Functionを呼び出してAI振り返りを生成:

```
POST /functions/v1/journal-reflect

Request:
{
  "entryId": "uuid",
  "content": "今日はバレンタインデー...",
  "mood": "good",
  "tags": ["恋愛", "イベント"]
}

Response:
{
  "reflection": "小さな幸せに気づけるの、素敵だね..."
}
```

#### AIプロンプト

```
あなたは{displayName}さんのAI分身です。
{displayName}さんの日記を読んで、短い振り返りコメントを書いてください。

ルール:
- 80〜150文字程度
- 共感を示す
- ユーザーの感情に名前をつける
- ポジティブな気づきを添える
- アドバイスは求められない限りしない
```

### 3.3 日記一覧

| 項目 | 仕様 |
|------|------|
| ソート | 作成日時の降順 |
| 表示 | 日付、気分アイコン、本文プレビュー（50文字）、タグ |
| グルーピング | 月ごとにセクション分け |
| ページネーション | 20件ずつ追加ロード |
| Freeユーザー | 直近7日分のみ表示（それ以前はブラー） |

### 3.4 日記編集・削除

| アクション | 仕様 |
|-----------|------|
| 編集 | 本文、気分、タグを変更可能。AI振り返りは再生成しない |
| 削除 | 確認ダイアログ後に論理削除 |

## 4. 感情トラッキング連携

日記作成時の気分選択は `mood_records` テーブルにも反映:

```typescript
// 日記保存時
const saveJournalEntry = async (input: JournalEntryInput) => {
  // 1. journal_entries に保存
  // 2. mood_records に当日の気分を記録（upsert）
  // 3. AI振り返り生成をリクエスト
};
```
