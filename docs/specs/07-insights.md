## 1. 概要

洞察（Insights）タブはPro専用。AIが日記・チャット・感情データを分析し、
ユーザーの思考パターン、感情の推移、成長を可視化する。

**目的**: データの蓄積を「可視化」して価値を実感させ、解約を防止する。

## 3. 機能仕様

### 3.1 気分グラフ（Mood Chart）

| 項目 | 仕様 |
|------|------|
| データソース | mood_records テーブル |
| 表示期間 | 直近7日（デフォルト）、14日、30日切り替え |
| グラフタイプ | 棒グラフ or ドットチャート（5段階） |
| 欠損データ | グレーアウト表示 |
| タップ動作 | 日付タップで該当日の日記にジャンプ |

### 3.2 デイリーAI洞察

毎日1回、その日の洞察をAIが生成して表示する。

#### 生成タイミング
- 朝9:00（ユーザーのタイムゾーン基準）にバッチ生成
- または初回アクセス時にオンデマンド生成

#### 洞察のデータソース
- 直近7日間のチャット履歴
- 直近7日間の日記
- 直近7日間の気分データ

#### API

```
POST /functions/v1/generate-insight

Request:
{
  "userId": "uuid",
  "type": "daily"
}

Response:
{
  "insight": "今週は仕事関連の話題が多かったね...",
  "topics": [
    { "name": "仕事", "percentage": 45 },
    { "name": "健康", "percentage": 20 },
    ...
  ]
}
```

#### AIプロンプト

```
あなたは{displayName}さんのAI分身です。
直近7日間の会話、日記、気分データを分析して、短い洞察コメントを書いてください。

分析データ:
- チャット履歴: {recentChats}
- 日記: {recentJournals}
- 気分推移: {moodTrend}

ルール:
- 100〜200文字程度
- パターンや変化に気づく
- ポジティブな変化は積極的に伝える
- 心配な兆候があれば優しく言及する
- データが少ない場合は「もっとお話しして教えてね」
```

### 3.3 トピック分析

チャットと日記のテキストからAIがトピック分類:

| 項目 | 仕様 |
|------|------|
| 分類方法 | AI（プロンプトベース）でトピック抽出 |
| 表示 | 横棒グラフ（%表示） |
| 分析期間 | 直近30日 |
| 更新頻度 | 週1回（日曜夜にバッチ） |
| デフォルトカテゴリ | 仕事、健康、人間関係、趣味、お金、学び、その他 |

### 3.4 月次成長レポート（クレジット消費）

| 項目 | 仕様 |
|------|------|
| 消費クレジット | 20 |
| 生成内容 | 1ヶ月間の総合分析レポート（500〜800文字） |
| 含む分析 | 気分推移サマリー、トピック変化、成長ポイント、来月の提案 |
| 出力形式 | アプリ内表示（Phase 2でPDF出力対応） |
| 生成上限 | 月1回（同月の再生成は追加クレジット不要） |

## 4. データ取得・キャッシュ戦略

### 4.1 データ取得

```typescript
// src/features/insights/hooks/use-insights.ts

type UseInsightsReturn = {
  moodData: MoodRecord[];
  dailyInsight: string | null;
  topics: Array<{ name: string; percentage: number }>;
  monthlyReport: string | null;
  isLoading: boolean;
  refreshInsight: () => Promise<void>;
  generateMonthlyReport: () => Promise<void>;
};
```

### 4.2 キャッシュ

| データ | キャッシュ戦略 |
|--------|------------|
| 気分データ | Zustand persist、5分間TTL |
| デイリー洞察 | Zustand persist、当日中有効 |
| トピック分析 | Zustand persist、週次更新 |
| 月次レポート | Supabase DB保存（永続） |
