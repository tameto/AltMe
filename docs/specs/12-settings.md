## 1. 概要

ユーザーがプロフィール、AIツイン設定、サブスクリプション、OpenClawインスタンスの状態を管理する。
アプリ全体の設定とProユーザー向けのインフラ管理機能を統合的に提供する。

## 4. 機能詳細

### 4.1 プロフィール編集

| 項目 | 仕様 |
|------|------|
| フィールド | 表示名（`profiles.display_name`） |
| 文字数制限 | 1-50文字 |
| バリデーション | 空文字不可。絵文字・日本語・英数字は全て許可 |
| 保存先 | `profiles.display_name` UPDATE |
| 保存後 | 成功トーストメッセージ + Zustand状態更新 |
| 変更検知 | 同じ名前の場合APIコールしない |

### 4.2 AIツイン設定

#### ツイン名変更

| 項目 | 仕様 |
|------|------|
| フィールド | ツイン名（`profiles.twin_name`） |
| 文字数制限 | 1-20文字 |
| 保存先 | `profiles.twin_name` UPDATE |
| Pro時の追加処理 | Edge Function `update-soul-md` 呼出（SOUL.md再生成） |
| インスタンス停止中 | DBのみ更新。次回起動時にSOUL.md反映 |

#### AIアイコン変更

| 項目 | 仕様 |
|------|------|
| 選択肢 | geometric / cosmic / organic / tech / zen（5パターン） |
| 保存先 | `profiles.avatar_icon` UPDATE |
| プレビュー | 選択時にプレビュー更新 |
| Pro時 | SOUL.md再生成トリガー |

#### 口調パターン変更

| 項目 | 仕様 |
|------|------|
| 選択肢 | polite / friendly / intellectual / mentor / tsundere（5種類） |
| 保存先 | `profiles.speech_tone` UPDATE |
| UI | 会話サンプルカード表示 |
| Pro時 | SOUL.md再生成トリガー（必須） |

#### MBTI入力

| 項目 | 仕様 |
|------|------|
| 入力方式 | 16タイプから選択（ドロップダウンまたは4x4グリッド） |
| 選択肢 | INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP, ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP |
| 任意入力 | 必須ではない（NULL許容） |
| 保存先 | `profiles.mbti_type` TEXT NULL |
| Pro時の追加処理 | Edge Function `update-soul-md` 呼出（SOUL.mdの `personality_traits` セクションにMBTI特性を追加） |
| MBTI特性反映例 | INTJ → 「論理的思考を好み、戦略的に物事を考える。独立心が強く、効率を重視する」 |
| インスタンス停止中 | DBのみ更新。次回起動時にSOUL.md反映 |
| ツイン情報画面連携 | Twin InfoタブにMBTIタイプを表示 |
| クリア | 設定済みのMBTIを削除可能（NULL に戻す） |

### 4.3 サブスクリプション管理

| 状態 | 表示内容 |
|------|---------|
| Free | 「Freeプラン」+ 「Proにアップグレード」ボタン |
| Trial | 「無料トライアル中（残りX日）」 |
| Pro (月額) | 「Proプラン（月額）」+ 次回更新日 |
| Pro (年額) | 「Proプラン（年額）」+ 次回更新日 |
| 解約済み | 「解約済み（YYYY/MM/DDまで有効）」 |
| RevenueCat APIエラー | 「状態を取得できませんでした」+ キャッシュ表示 |

### 4.4 OpenClawインスタンス管理（Pro限定）

#### ステータス表示

| ステータス | バッジ | 色 | アイコン |
|-----------|--------|-----|---------|
| provisioning | セットアップ中... | 黄色 (#F59E0B) | clock |
| running | 稼働中 | 緑色 (#10B981) | check-circle |
| stopped | 停止中 | グレー (#6B7280) | stop-circle |
| error | エラー | 赤色 (#EF4444) | exclamation-circle |
| destroying | 削除中... | 黄色 (#F59E0B) | clock |

#### 再起動機能

| 項目 | 仕様 |
|------|------|
| 表示条件 | error または running ステータス時 |
| 確認ダイアログ | 「インスタンスを再起動しますか？」 |
| 呼出先 | Edge Function `restart-openclaw` |
| タイムアウト | 120秒 |
| クールダウン | 5分以内に3回以上はブロック |
| 成功時 | ステータスが provisioning -> running に遷移 |
| 二重実行防止 | ボタン非活性化 |

#### リアルタイム更新

`openclaw_instances` テーブルを Supabase Realtime でサブスクライブ。ステータス変更が即座にUIに反映される。

### 4.5 通知設定

#### 通知カテゴリ

| カテゴリ | デフォルト | 設定項目 |
|---------|----------|---------|
| チャット通知 | ON | AIツインからの返信時（アプリがバックグラウンドの場合のみ） |
| 日記リマインダー | ON | 毎日通知（時刻設定可能、デフォルト21:00） |
| コミュニティ通知 | ON | 自分のエージェントが発言した時 |
| マーケティング通知 | OFF | キャンペーン通知（管理側から送信） |

#### 保存先

| テーブル | カラム | 型 | デフォルト |
|---------|--------|------|---------|
| `notification_settings` | `user_id` | UUID PK (REFERENCES profiles(id)) | — |
| `notification_settings` | `chat_enabled` | BOOLEAN | true |
| `notification_settings` | `journal_reminder_enabled` | BOOLEAN | true |
| `notification_settings` | `journal_reminder_time` | TIME | '21:00' |
| `notification_settings` | `community_enabled` | BOOLEAN | true |
| `notification_settings` | `marketing_enabled` | BOOLEAN | false |

#### プッシュトークン管理

| テーブル | カラム | 型 | 説明 |
|---------|--------|------|------|
| `push_tokens` | `id` | UUID PK | — |
| `push_tokens` | `user_id` | UUID FK | auth.users 参照 |
| `push_tokens` | `expo_push_token` | TEXT | Expo Push Token |
| `push_tokens` | `device_id` | TEXT | デバイス識別子 |
| `push_tokens` | `platform` | TEXT | ios / android |
| `push_tokens` | `created_at` | TIMESTAMPTZ | 作成日時 |
| `push_tokens` | `updated_at` | TIMESTAMPTZ | 更新日時 |

#### 動作仕様

| 項目 | 仕様 |
|------|------|
| トークン登録 | アプリ起動時に Expo Push Token を取得し `push_tokens` テーブルに upsert |
| 通知送信 | Edge Function `send-push-notification` が Expo Push API を呼び出し |
| OS設定連携 | デバイスのシステム通知設定がOFFの場合、アプリ内でその旨を表示 |
| 権限リクエスト | 初回起動時に通知権限をリクエスト |

### 4.6 ログアウト

```
ログアウトタップ
  -> 確認ダイアログ「本当にログアウトしますか？」
  -> 「ログアウト」タップ
  -> OpenClaw WebSocket接続切断
  -> Supabaseセッション無効化（supabase.auth.signOut）
  -> SecureStoreからトークン削除
  -> Zustand全状態リセット
  -> ローカルキャッシュクリア
  -> ログイン画面にリダイレクト
```

ネットワークエラー発生時でも、ローカルのセッション・キャッシュは必ず削除される。

### 4.7 アカウント削除

```
アカウント削除タップ
  -> 確認モーダル表示
  -> 「削除」テキスト入力確認（完全一致で削除ボタン活性化）
  -> 「削除を確定」タップ
  -> 1. OpenClawインスタンス破棄（destroy-openclaw、存在する場合）
  -> 2. RevenueCatサブスクリプションキャンセル
  -> 3. Supabase全ユーザーデータCASCADE削除
  -> 4. Supabase Auth ユーザー削除
  -> ログイン画面にリダイレクト
```

| 注意点 | 仕様 |
|--------|------|
| OpenClawインスタンス削除失敗 | ユーザーアカウント削除は続行 |
| ネットワークエラー | リトライまたはサポート連絡を案内 |
| Apple審査基準 | 削除ボタンは設定画面内で容易に見つかる位置に配置 |
| 削除対象 | チャット履歴、性格診断結果、日記データ、OpenClawインスタンス |

## 5. データ仕様

### 使用テーブル

| テーブル | 操作 | 用途 |
|---------|------|------|
| `profiles` | SELECT / UPDATE | 表示名・ツイン名・アイコン・口調・MBTIの読み書き |
| `openclaw_instances` | SELECT | インスタンスステータス表示 |
| `personality_results` | INSERT | 性格診断やり直し時の新規レコード |
| `subscriptions` | SELECT | サブスクリプション状態表示 |
| `notification_settings` | SELECT / UPSERT | 通知カテゴリごとのON/OFF設定 |
| `push_tokens` | SELECT / UPSERT | Expo Push Token の登録・更新 |

### Edge Function

| Function | 用途 | トリガー |
|----------|------|---------|
| `update-soul-md` | SOUL.md再生成 | ツイン名・アイコン・口調・MBTI変更時（Pro） |
| `restart-openclaw` | インスタンス再起動 | 再起動ボタンタップ時 |
| `destroy-openclaw` | インスタンス破棄 | アカウント削除時 |
| `send-push-notification` | プッシュ通知送信 | Expo Push API 経由で通知配信 |

### 外部API

| API | 用途 |
|-----|------|
| RevenueCat SDK `getCustomerInfo` | サブスクリプション情報取得 |
| Supabase Auth `signOut` | ログアウト |
| Supabase Realtime | `openclaw_instances` ステータス監視 |
| Expo Push API | プッシュ通知送信（`send-push-notification` 経由） |

## 7. エラーハンドリング

| ケース | 対応 |
|--------|------|
| ネットワーク未接続時にプロフィール保存 | 「ネットワークに接続してください」エラー表示 |
| OpenClawインスタンス状態取得タイムアウト | キャッシュ表示 + 「最終更新: X分前」注記 |
| RevenueCat APIエラー | キャッシュまたは「取得できませんでした」表示 |
| SOUL.md更新エラー | DB更新は成功として扱い、SOUL.md更新はバックグラウンドリトライ |
| 再起動タイムアウト（120秒） | 「再起動に失敗しました。サポートに連絡してください」 |
| 表示名にHTML/スクリプトタグ | サニタイズして保存 |
| 同時に複数フィールド編集中にアプリ終了 | 未保存の変更は破棄（MVPのため） |

## 8. 検証条件

- [ ] 表示名を変更して保存できること
- [ ] AIツイン名を変更して保存できること
- [ ] AIアイコンを5パターンから選択して保存できること
- [ ] 口調パターンを5種類から選択して保存できること
- [ ] アイコン・口調変更時にSOUL.md再生成がトリガーされること（Pro）
- [ ] Proユーザーがサブスクリプション情報を確認できること
- [ ] Proユーザーがインスタンスステータスを確認できること
- [ ] errorステータスのインスタンスを再起動できること
- [ ] ログアウトで全セッション・キャッシュがクリアされること
- [ ] アカウント削除で全データが削除され、ログイン画面に遷移すること
- [ ] 性格診断やり直しでオンボーディングに遷移できること
- [ ] 通知設定のON/OFFが反映されること
- [ ] MBTI を16タイプから選択して保存できること
- [ ] MBTI設定後にSOUL.md再生成がトリガーされること（Pro）
- [ ] MBTI設定をクリア（未設定に戻す）できること
- [ ] 日記リマインダーの時刻を変更できること
- [ ] プッシュトークンがアプリ起動時に登録されること
- [ ] 通知カテゴリごとのON/OFF切り替えが反映されること

### 異常系
- [ ] ネットワークエラー時にプロフィール保存がエラー表示されること
- [ ] SOUL.md再生成失敗でDB更新は成功として扱われること
- [ ] インスタンス再起動タイムアウト時に適切なメッセージが表示されること
- [ ] ログアウト中のネットワークエラーでもローカル状態がクリアされること
- [ ] アカウント削除時のネットワークエラーで適切なメッセージが表示されること

### 境界値
- [ ] 表示名の最大文字数（50文字）
- [ ] ツイン名の最大文字数（20文字）
- [ ] 空文字でのバリデーションエラー
- [ ] 再起動クールダウン（5分以内に3回）
- [ ] 日記リマインダー時刻の範囲（00:00-23:59）

### 表示
- [ ] 無料ユーザーにOpenClawセクションが表示されないこと
- [ ] 各インスタンスステータスのバッジが正しい色で表示されること
- [ ] アカウント削除ボタンが設定画面内で見つけやすい位置にあること（Apple審査基準）
- [ ] MBTIが16タイプの選択グリッド/ドロップダウンで表示されること
- [ ] 通知設定セクションに4カテゴリが表示されること
- [ ] OS設定で通知がOFFの場合にアプリ内で警告が表示されること

### セキュリティ
- [ ] 他ユーザーのプロフィールを編集できないこと（RLS）
- [ ] 他ユーザーのアカウントを削除できないこと（RLS）
- [ ] アカウント削除時に確認テキスト入力が正しく機能すること
